# 환경 변수 정리

런타임 `SIMA_*` 코드에서 참조되는 변수는 구성의 복잡성을 줄이기 위해 네 가지 범주로 분류됩니다. 각 변수는 아래 목록에 정확히 한 번씩 나타납니다.

## 합계

- `SIMA_*`에서 런타임 변수 148개 발견 (`src/` + `include/`).
- `Retired in this pass`: 6
- `Unify` (디버그 프로필 수를 줄임): 47
- `Framework knob` (타입이 지정된 API 옵션으로 승격): 34
- `Keep as-is` (개발자 진단 / 플랫폼 설정): 67

## 이번 경기에서 은퇴합니다.

이러한 항목들은 임시 코드, 아무런 기능도 하지 않는 코드, 또는 이전 버전의 코드를 대체하기 위한 코드였으며, 현재는 런타임 코드에서 제거되었습니다.

- SIMA_BOXDECODE_WIRE_DEBUG
- SIMA_DETESS_MULTI_BUFFER
- SIMA_FORCE_POOL_RELEASE
- SIMA_GUARD_TEST_HOLD_MS
- SIMA_MLA_CONFIG_DEBUG
- SIMA_SYNC_RUN_NUM_BUFFERS
