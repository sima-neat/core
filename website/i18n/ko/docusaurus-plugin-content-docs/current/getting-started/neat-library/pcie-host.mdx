이 페이지를 사용하여 Linux 시스템에 Neat PCIe 호스트 패키지를 설치하고, Modalix PCIe 카드에 연결합니다.

Neat PCIe 호스트 패키지는 호스트 시스템에서 연결된 Modalix PCIe 카드로 입력을 전송하고 추론 결과를 수신하기 위한 공동 처리 API를 제공합니다.

:::warning PCIe 호스트 장치에 설치합니다.
이 설치 프로그램을 **PCIe 호스트 시스템**에 연결된 Modalix PCIe 카드에서 실행합니다. Neat SDK 컨테이너 내부, DevKit 또는 Modalix PCIe 카드에서 실행하지 마십시오.
:::

## 지원되는 호스트 운영체제

Neat PCIe 호스트 패키지는 다음의 검증된 호스트 플랫폼을 지원합니다.

| 운영체제 | 아키텍처 | 지원 |
|---|---|---|
| Ubuntu 22.04 | x86_64 | 지원 |
| Ubuntu 24.04 | x86_64 | 지원 |

Arm64 호스트 빌드는 아직 검증되지 않았습니다. Windows 11은 지원되지 않습니다.

## 필수 조건

패키지를 설치하기 전에:

- PCIe 호스트에 `sima-cli`를 설치합니다. [sima-cli 설치 안내서](/tools/sima-cli/)를 참조하세요.
- [PCIe 드라이버 설치 안내서](https://developer.sima.ai/hardware/getting-started/pcie-mode/driver-installation)에 따라 PCIe 호스트 드라이버를 설치하고 확인합니다.
- Modalix PCIe 카드를 연결하고 구성하여 호스트에서 관리 인터페이스에 접근할 수 있도록 합니다. 카드 0의 기본 주소는 `10.0.0.2`입니다.
- 카드에 호환되는 Neat Library 버전을 설치합니다. 호스트 및 카드 패키지는 호환되는 버전에서 제공되어야 합니다.

PCIe 호스트를 인증하여 SiMa.ai 아티팩트를 다운로드할 수 있도록 합니다.

<ShellCommand prompt="pcie-host">
sima-cli login
</ShellCommand>

## PCIe 호스트 패키지 설치

PCIe 호스트에서 작업 디렉터리를 선택한 다음, 설치된 Ubuntu 버전에 해당하는 명령을 실행합니다.

**x86_64 아키텍처에서 Ubuntu 22.04:**

<ShellCommand prompt="pcie-host">
sima-cli neat install core/pciehost/ubuntu22/amd64@v0.4.0
</ShellCommand>

**x86_64 아키텍처 기반의 Ubuntu 24.04:**

<ShellCommand prompt="pcie-host">
sima-cli neat install core/pciehost/ubuntu24/amd64@v0.4.0
</ShellCommand>

설치 프로그램은 C++ API와 `~/pyneatpcie`에 있는 Python 환경을 포함하여 Neat PCIe 호스트 애플리케이션을 개발하고 실행하는 데 필요한 모든 것을 추가합니다.

처음 설치하는 동안 SSH 프로비저닝은 카드에 대한 `sima` 계정의 비밀번호를 요청할 수 있습니다. 그런 다음 `~/.ssh/sima_neat_pcie_ed25519`를 생성하거나 재사용하고 해당 공개 키를 카드에 설치합니다. 이후 일반적인 PCIe 작동은 카드 측 모델 설정을 위해 비밀번호 없는 SSH를 사용합니다.

## 설치 확인

Python API와 PCIe 호스트 플러그인이 설치되어 있는지 확인합니다.

<ShellCommand prompt="pcie-host">
source ~/pyneatpcie/bin/activate
python3 -c "import pyneatpcie; print('pyneatpcie ready')"
gst-inspect-1.0 neatpciehost
</ShellCommand>

## 문제 해결

SSH 프로비저닝으로 카드를 자동으로 검색할 수 없는 경우, 먼저 호스트가 관리 주소에 접속할 수 있는지 확인하십시오.

<ShellCommand prompt="pcie-host">
ping -c 1 10.0.0.2
</ShellCommand>

그런 다음 설치된 설정 유틸리티를 실행하고 주소를 명시적으로 지정합니다.

<ShellCommand prompt="pcie-host">
pcie-setup.sh --hosts "10.0.0.2"
</ShellCommand>

패키지 설치 또는 런타임 시작에 실패하는 경우, PCIe 호스트 패키지와 카드에 설치된 Neat Library가 호환되는 버전인지 확인하십시오.
