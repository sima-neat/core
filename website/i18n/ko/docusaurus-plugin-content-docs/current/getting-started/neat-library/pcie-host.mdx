이 페이지를 사용하여 Linux 시스템에 Neat PCIe 호스트 패키지를 설치하고, Modalix PCIe 카드에 연결합니다.

Neat PCIe 호스트 패키지는 호스트 시스템에서 연결된 Modalix PCIe 카드로 입력을 보내고 추론 결과를 수신하기 위한 공동 처리 API를 제공합니다.

:::warning PCIe 호스트 장치에 설치합니다.
이 설치 프로그램을 Modalix PCIe 카드에 연결된 **PCIe 호스트 시스템**에서 실행합니다. Neat SDK 컨테이너 내부, DevKit 또는 Modalix PCIe 카드에서 실행하지 마십시오.
:::

:::tip 오프라인 설치가 필요한 경우
대상에서 SiMa.ai 서비스의 패키지를 다운로드할 수 없으면 [오프라인 설치](#offline-installation)를 사용하세요.
인터넷에 연결된 컴퓨터에서 패키지를 다운로드하세요.
:::

## 지원되는 호스트 운영체제

Neat PCIe 호스트 패키지는 다음으로 검증된 호스트 플랫폼을 지원합니다.

| 운영 체제 | 아키텍처 | 지원 |
| --- | --- | --- |
| 우분투 22.04 | x86_64 | 지원됨 |
| 우분투 24.04 | x86_64 | 지원됨 |

Arm64 호스트 빌드는 아직 검증되지 않았습니다. Windows 11은 지원되지 않습니다.

## 온라인 설치 필수 조건

패키지를 설치하기 전에:

- PCIe 호스트에 `sima-cli`를 설치합니다. 다음을 사용하십시오.
  [sima-cli installation guide](/tools/sima-cli/).
- 다음 단계를 따라 PCIe 호스트 드라이버를 설치하고 확인하십시오.
  [PCIe Driver Installation guide](https://developer.sima.ai/hardware/getting-started/pcie-mode/driver-installation).
- Modalix PCIe 카드를 연결하고 구성하여 관리 인터페이스를 사용할 수 있도록 합니다.
  호스트에서 접근할 수 있습니다. 카드 0의 기본 주소는 `10.0.0.2`입니다.
- 카드에 호환되는 Neat Library 버전을 설치합니다. 호스트와
  카드 패키지는 호환되는 버전에서 제공되어야 합니다.

PCIe 호스트를 인증하여 SiMa.ai 아티팩트를 다운로드할 수 있도록 합니다.

<ShellCommand prompt="pcie-host">
sima-cli login
</ShellCommand>

## PCIe 호스트 패키지를 설치합니다.

PCIe 호스트에서 작업 디렉터리를 선택한 다음, 설치된 Ubuntu 버전에 맞는 명령을 실행합니다.

**x86_64 아키텍처의 Ubuntu 22.04:**

<ShellCommand prompt="pcie-host">
sima-cli neat install core/pciehost/ubuntu22/amd64@v%%release.core%%
</ShellCommand>

**x86_64 아키텍처 기반의 Ubuntu 24.04:**

<ShellCommand prompt="pcie-host">
sima-cli neat install core/pciehost/ubuntu24/amd64@v%%release.core%%
</ShellCommand>

설치 프로그램은 C++ API와 `~/pyneatpcie`에 있는 Python 환경을 포함하여 Neat PCIe 호스트 애플리케이션을 개발하고 실행하는 데 필요한 모든 것을 추가합니다.

패키지에 포함된 Codex 및 Claude용 코딩 에이전트 스킬 `neat-pcie-application-builder`도 설치합니다. PCIe 호스트 패키지를 다시 설치하면 설치된 스킬도 해당 패키지 버전에 맞게 업데이트됩니다.

처음 설치하는 동안 SSH 프로비저닝은 카드에 대한 `sima` 계정의 비밀번호를 요청할 수 있습니다. 그런 다음 `~/.ssh/sima_neat_pcie_ed25519`를 생성하거나 재사용하고 해당 공개 키를 카드에 설치합니다. 이후 일반적인 PCIe 작동은 카드 측 모델 설정을 위해 비밀번호 없는 SSH를 사용합니다.

## 온라인 설치 확인

Python API와 PCIe 호스트 플러그인이 설치되어 있는지 확인합니다.

<ShellCommand prompt="pcie-host">
source ~/pyneatpcie/bin/activate
python3 -c "import pyneatpcie; print('pyneatpcie ready')"
gst-inspect-1.0 neatpciehost
</ShellCommand>

## 문제 해결

SSH 프로비저닝으로 카드를 자동으로 검색할 수 없는 경우, 먼저 호스트가 관리 주소에 접속할 수 있는지 확인하십시오.

<ShellCommand prompt="pcie-host">
ping -c 1 10.0.0.2
</ShellCommand>

그런 다음 설치된 설정 유틸리티를 실행하고 주소를 명시적으로 지정합니다.

<ShellCommand prompt="pcie-host">
pcie-setup.sh --hosts "10.0.0.2"
</ShellCommand>

패키지 설치 또는 런타임 시작에 실패하는 경우, PCIe 호스트 패키지와 카드에 설치된 Neat Library가 호환되는 버전인지 확인하십시오.

## 오프라인 설치 {#offline-installation}

:::caution 설치 전에 Python 의존성 확인
오프라인 설치는 기존 Python 환경과 추가 패키지 및 파일을 보존합니다. 패키지를 설치하기 전에 `pip check`를 실행합니다. 환경이 이미 손상된 경우 설치를 중단하고 환경 경로와 의존성 오류를 표시합니다. 보고된 의존성을 복구한 후 다시 시도하세요. 오프라인 복구에는 추가 wheel 파일이 필요합니다. 설치 후에도 의존성을 검사하여 남아 있거나 새로 발생한 충돌을 보고합니다. 패키지 변경 사항은 자동으로 롤백되지 않습니다.

환경을 삭제하고 새로 설치하려는 경우에만 `./install.sh --recreate-venv`(독립형 Core) 또는 `sudo python3 -B install.py --recreate-venv`(PCIe)를 명시적으로 실행하세요. 선택한 환경의 패키지와 파일은 백업 없이 삭제됩니다. SDK에서는 이 옵션이 SDK 호스트 Python이 아닌 페어링된 DevKit에 적용됩니다. 필요한 파일을 먼저 저장하세요. 사전 검사 및 검증 전용 명령은 환경을 다시 만들지 않습니다.
:::

Neat PCIe 오프라인 패키지는 0.6.0 이상 버전에서 사용할 수 있습니다.

PCIe 패키지는 호스트와 연결된 모든 호환 카드에 Neat를 설치합니다.
이 설치에는 대상 시스템의 Docker 또는 인터넷 연결이 필요하지 않습니다.
호스트에서 각 카드로 연결되는 PCIe 네트워크가 정상적으로 작동해야 합니다.

### 1. 호스트 및 카드 준비

Neat 설치 프로그램을 실행하기 전에 다음 작업을 완료하세요:

- 호환되는 Platform 호스트 드라이버를 설치하세요.
- 각 카드에 맞는 Platform 3.0 펌웨어를 설치하세요.
- 각 카드의 PCIe 인터페이스에서 검색 기능을 설정하세요.
- 각 카드에 고유한 PCIe IPv4 주소를 할당하세요.
- 각 카드에서 SSH 서버를 활성화하고 로그인 비밀번호를 준비하세요.
- SSH 계정에 각 카드에서 `sudo`를 사용할 권한을 부여하세요.

Neat 설치 프로그램은 Platform 드라이버를 설치하거나 Platform 펌웨어를 변경하지 않습니다.
Platform 릴리스에 포함된 시스템 설정 지침을 사용하세요.

### 2. 패키지 다운로드

인터넷에 연결된 컴퓨터에 `sima-cli`를 설치하세요. [sima-cli 설치 가이드](/tools/sima-cli/)를 참조하세요.

대상 호스트에 맞는 0.6.0 이상 버전을 선택하세요.
패키지는 `amd64` 또는 `arm64` 프로세서를 사용하는 Ubuntu 22.04 및 24.04 호스트를 지원합니다.

이 예제는 인터넷에 연결된 컴퓨터에서 %%release.core%% 버전을 다운로드합니다.
Ubuntu 24.04 `amd64` 대상 호스트의 경우 다음을 실행하세요:

<ShellCommand prompt="host">
sima-cli neat install 'core/pciehost/ubuntu24/amd64@v%%release.core%%' -t offline -d ./pcie-offline
</ShellCommand>

Ubuntu 22.04의 경우 `ubuntu24`를 `ubuntu22`로 바꾸세요.
`arm64` 호스트의 경우 `amd64`를 `arm64`로 바꾸세요.
이 명령은 패키지를 다운로드하고 압축을 풉니다. Neat를 설치하지는 않습니다.

### 3. 선택 사항: 준비된 시스템 확인

1. 전체 `pcie-offline` 디렉터리를 대상 호스트에 복사하세요. 공백이 없는 경로를 사용하세요.
2. 압축을 푼 `neat-offline` 디렉터리를 여세요. 이 디렉터리에는 `install.py`가 있습니다.
3. 필요한 시스템 도구와 SSH 설정은 제공된 `INSTALL.md`를 읽어 확인하세요.
4. SSH 액세스가 이미 구성되어 있으면 검사를 실행하세요:

<ShellCommand prompt="host">
sudo python3 -B install.py --preflight-only
</ShellCommand>

설치 프로그램은 연결된 모든 카드를 자동으로 검색합니다. 카드 IP 주소를 제공하지 마세요.
검사는 임시 파일을 생성하지만 패키지를 설치하거나 SSH를 구성하지 않습니다.
새 호스트에서는 설치 단계로 진행하면 설치 프로그램이 대화형으로 SSH를 설정합니다.
그 밖에 보고된 오류는 설치 전에 수정하세요.

### 4. 설치 및 결과 확인

같은 디렉터리에서 다음 명령을 실행하세요:

<ShellCommand prompt="host">
sudo python3 -B install.py
</ShellCommand>

새 호스트에서는 설치 프로그램이 `sudo`를 실행한 사용자의 `~/.ssh/sima_neat_pcie_ed25519`를 생성하거나 재사용하고 온라인 설치와 동일한 설정 스크립트로 검색된 모든 카드에 대한 SSH 액세스를 설정합니다. 필요한 경우 카드 로그인 비밀번호를 입력하세요. `ssh-keygen`이나 `ssh-copy-id`를 별도로 실행하거나 카드 IP 주소를 입력할 필요가 없습니다.

기존 자격 증명을 선택하려면 `--ssh-user`와 `--ssh-key`를 사용하세요. 명시적으로 지정하는 `--ssh-key`는 암호 문구가 없는 기존 키여야 합니다. 자동 등록은 `~/.ssh/known_hosts`를 사용합니다. 사용자 지정 `--known-hosts` 파일은 미리 구성해야 합니다. 무인 설치에는 미리 구성된 SSH 액세스가 필요합니다. 비밀번호는 터미널에서 입력하며 로그에 저장하거나 명령 인수로 전달하지 않습니다.

설치 프로그램은 패키지를 설치하기 전에 모든 카드를 확인합니다.
먼저 호스트를 설치하고 검증한 다음 각 카드를 차례로 처리합니다.
최종 요약에서 호스트와 모든 카드의 설치 및 검증이 성공했는지 확인하세요.
그런 다음 애플리케이션 인수 테스트를 실행하세요.

설치가 실패하면 표시된 경로의 진단 로그를 읽으세요.
설치 중 카드 연결이 실패하면 다시 시도하기 전에 해당 카드의 설치 프로세스가 중지되었는지 확인하세요.
설치 프로그램은 실패 후 이전 설치 상태를 자동으로 복원하지 않습니다.

## 다음 단계

[PCIe 공동 처리](/develop-apps/hello-neat/pcie/)을 계속 진행하여 호스트에서 카드까지의 전체 개발 경로를 확인합니다.

오프라인 설치는 호스트의 기존 `~/pyneatpcie` 또는 카드나 DevKit의 기존 `~/pyneat`를 재사용하며, 심볼릭 링크인 경우 링크 대상을 재사용합니다. 홈 환경이 없으면 설치 사용자가 NVMe에 쓸 수 있는 경우 `/media/nvme/pyneat`를 사용하고, 그렇지 않으면 `~/pyneat`를 사용합니다. 새 NVMe 설치는 기존 홈 환경을 교체하지 않고 `~/pyneat` 링크를 만듭니다.
