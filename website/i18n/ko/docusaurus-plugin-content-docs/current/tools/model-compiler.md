# Model Compiler

Model Compiler은 학습된 모델을 Neat에서 로드하고 실행할 수 있는 Modalix 형식의 모델 아카이브로 변환합니다.

다음과 같은 경우에 사용하세요.

- 모델이 SiMa.ai 플랫폼과 호환되는지 확인합니다.
- 지원되는 모델을 양자화하고 컴파일합니다.
- Neat 앱에서 아카이브를 사용하기 전에 정확도와 성능을 검증합니다.

작업 흐름의 경우, [모델을 컴파일합니다.](/compile-a-model/)부터 시작합니다. API 관련 참고 자료는 [Model Compiler API](/reference/model-sdk-api/)를 참조하십시오.
