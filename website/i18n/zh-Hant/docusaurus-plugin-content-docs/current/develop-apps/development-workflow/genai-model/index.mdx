# GenAI 模型

Neat 使用 GenAI API，適用於使用 LLiMa 準備的 LLM、VLM 和 ASR 模型。這是 [`Model`](/develop-apps/development-workflow/model) 的生成式模型對應版本：載入已部署的模型目錄，建立請求，然後在您的應用程式中執行或透過 HTTP 提供服務。

當您的應用程式要求模型生成文字、回答有關影像的問題、呼叫工具或轉錄音訊時，請使用這些 API。對於固定形狀的判別模型（例如分類、檢測、分割或嵌入模型），請使用傳統的 `Model` API。

## GenAI 的應用

GenAI 的流程與 Neat 的其餘部分具有相同的整體結構：

1. 準備或下載用於 Modalix 的模型成品。
2. 將模型放置在目標位置，通常位於 `/media/nvme/llima/models/` 下。
3. 從您的 C++ 或 Python 應用程式中載入模型。
4. 直接發送請求，或透過 `GenAIServer` 公開模型。
5. 讀取完整的結果或使用串流輸出。

LLiMa 負責 GenAI 模型的準備、命令行測試和基準測試。
Neat 負責應用程式介面的 API 和執行階段整合，一旦模型在您的應用程式中使用。有關模型準備的詳細資訊，請參閱 [搭配 LLiMa 的生成式 AI](/genai-llima/)。
