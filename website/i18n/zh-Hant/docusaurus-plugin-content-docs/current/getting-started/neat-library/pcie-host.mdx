請使用此頁面，在已連接至 Modalix PCIe 卡的 Linux 主機上安裝 Neat PCIe 主機套件。

Neat PCIe 主機封裝提供協同處理 API，用於將來自主機的輸入傳送到連接的 Modalix PCIe 卡，並接收推論結果。

:::warning 安裝於 PCIe 主機上。
請在連接到 Modalix PCIe 卡的 **PCIe 主機**上執行此安裝。請勿在 Neat SDK 容器、DevKit 或 Modalix PCIe 卡上執行。
:::

## 支援的主機作業系統

Neat PCIe 主機封裝支援下列已驗證的主機平台：

| 作業系統 | 架構 | 支援 |
|---|---|---|
| Ubuntu 22.04 | x86_64 | 已支援 |
| Ubuntu 24.04 | x86_64 | 已支援 |

Arm64 主機上的建置尚未經過驗證。Windows 11 不受支援。

## 先決條件

在安裝套件之前：

- 在 PCIe 主機上安裝 `sima-cli`。請參考
  [sima-cli 安裝指南](/tools/sima-cli/)。
- 按照 [PCIe 驅動程式安裝指南](https://developer.sima.ai/hardware/getting-started/pcie-mode/driver-installation) 的步驟安裝並驗證 PCIe 主機驅動程式。
- 連接並設定 Modalix PCIe 卡，使其管理介面可以從主機存取。卡 0 的預設位址為 `10.0.0.2`。
- 在卡上安裝相容的 Neat Library 版本。主機和卡上的套件必須來自相容的版本。

驗證 PCIe 主機，以便它可以下載 SiMa.ai 成品：

<ShellCommand prompt="pcie-host">
sima-cli login
</ShellCommand>

## 安裝 PCIe 主機套件

在 PCIe 主機上選擇一個工作目錄，然後執行適用於已安裝的 Ubuntu 版本的指令。

**Ubuntu 22.04 於 x86_64 平台上：**

<ShellCommand prompt="pcie-host">
sima-cli neat install core/pciehost/ubuntu22/amd64@v0.4.0
</ShellCommand>

**Ubuntu 24.04 於 x86_64 平台上：**

<ShellCommand prompt="pcie-host">
sima-cli neat install core/pciehost/ubuntu24/amd64@v0.4.0
</ShellCommand>

安裝程式會新增所有必要的元件，以便開發和執行 Neat PCIe 主機應用程式，包括 C++ API 和位於 `~/pyneatpcie` 的 Python 環境。

在第一次安裝期間，SSH 設定程序可以要求提供卡片的 `sima` 帳戶密碼。它會建立或重新使用 `~/.ssh/sima_neat_pcie_ed25519`，並將其公鑰安裝到卡片上。之後，正常的 PCIe 作業會使用無密碼的 SSH 來進行卡片端模型的設定。

## 驗證安裝程序

確認 Python API 和 PCIe 主機外掛程式是否已安裝：

<ShellCommand prompt="pcie-host">
source ~/pyneatpcie/bin/activate
python3 -c "import pyneatpcie; print('pyneatpcie ready')"
gst-inspect-1.0 neatpciehost
</ShellCommand>

## 疑難排解

如果 SSH 佈線無法自動偵測到卡片，請先確認主機是否能夠連線到其管理位址：

<ShellCommand prompt="pcie-host">
ping -c 1 10.0.0.2
</ShellCommand>

然後以明確指定的位址執行已安裝的設定工具：

<ShellCommand prompt="pcie-host">
pcie-setup.sh --hosts "10.0.0.2"
</ShellCommand>

如果套件安裝或執行階段啟動失敗，請確認 PCIe 主機套件以及安裝在卡上的 Neat Library，是否來自相容的版本。
