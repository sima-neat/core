# Model Compiler

Model Compiler 將訓練好的模型轉換為 Modalix 格式的模型封存檔，以便 Neat 能夠載入和執行。

當您需要時，請使用它：

- 檢查模型是否與 SiMa.ai 平台相容；
- 量化並編譯受支援的模型；
- 在將檔案用於 Neat 應用程式之前，驗證其準確性和效能。

對於任務流程，請從 [編譯模型](/compile-a-model/) 開始。如需 API 參考資料，請參閱 [Model Compiler API](/reference/model-sdk-api/)。
