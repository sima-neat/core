Використовуйте цю довідку лише для випусків SDK, які потребують окремого завантаження образу та окремої команди налаштування. Це стосується SDK 2.0.0, SDK 2.1.2.0 і SDK 2.1.2.1. Новіші випуски SDK використовують спрощений процес встановлення пакета, описаний у розділі [Встановлення SDK](/getting-started/dev-environment/install-the-environment/).

Застаріле встановлення SDK складається з двох кроків:

1. Завантажте образ контейнера SDK.
2. Запустіть налаштування SDK, щоб створити робочий простір і, за потреби, під’єднати DevKit.

## Завантажте образ SDK

Запустіть на хості команду встановлення образу, яка відповідає вашому випуску SDK.

Для SDK 2.0.0:

<ShellCommand prompt="host">
sima-cli install ghcr:sima-neat/sdk:v2.0.0
</ShellCommand>

Для SDK 2.1.2 або 2.1.2.1 використовуйте відповідний тег образу 2.1, що постачається з цим випуском.

Перше встановлення може тривати кілька хвилин, оскільки під час нього завантажується образ контейнера SDK.

## Запустіть налаштування SDK

Якщо ваш DevKit доступний із хоста, під’єднайте його під час налаштування:

<ShellCommand prompt="host">
sima-cli sdk setup --devkit {devkit-ip}
</ShellCommand>

Якщо ваш DevKit поки недоступний, налаштуйте робочий простір SDK без під’єднання:

<ShellCommand prompt="host">
sima-cli sdk setup
</ShellCommand>

Під час налаштування `sima-cli` може попросити вас вибрати встановлений образ SDK, вибрати каталог робочого простору на хості та налаштувати каталог розширень SDK. З `--devkit` налаштування також запитує параметри підключення до DevKit і налаштовує DevKit Sync.

## Відкрийте оболонку SDK

Після успішного налаштування відкрийте оболонку SDK:

<ShellCommand prompt="host">
sima-cli sdk neat
</ShellCommand>

## Сумісність

SDK 2.0.0 призначено для програмного забезпечення DevKit 2.0.0. SDK 2.1.2 і 2.1.2.1 призначено для програмного забезпечення DevKit 2.1.2. Актуальні рекомендації щодо сумісності див. у розділі [Сумісність](/getting-started/compatibility/).
