Використовуйте цю інструкцію лише для версій SDK, які потребують окремого завантаження образу та команди налаштування. Це стосується SDK 2.0.0, SDK 2.1.2.0 та SDK 2.1.2.1. У новіших версіях SDK використовується спрощена процедура встановлення, описана в [Встановіть необхідне програмне забезпечення.](/getting-started/dev-environment/install-the-environment/).

Встановлення старої версії SDK складається з двох кроків:

1. Завантажте образ контейнера SDK.
2. Запустіть програму налаштування SDK, щоб створити робочий простір і, за бажанням, під’єднати DevKit.

## Завантажте образ SDK.

Запустіть команду для встановлення образу, яка відповідає версії вашого SDK, на хості.

Для SDK 2.0.0:

<ShellCommand prompt="user-host-machine">
sima-cli install ghcr:sima-neat/sdk:v2.0.0
</ShellCommand>

Для SDK версії 2.1.2 або 2.1.2.1 використовуйте відповідний образ (image tag) версії 2.1, який постачається разом із цією версією.

Перше встановлення може тривати кілька хвилин, оскільки відбувається завантаження контейнерного образу SDK.

## Запустіть програму налаштування SDK.

Якщо ваш DevKit доступний з хоста, під’єднайте його під час налаштування:

<ShellCommand prompt="user-host-machine">
sima-cli sdk setup --devkit {devkit-ip}
</ShellCommand>

Якщо ваш DevKit ще недоступний, налаштуйте робоче середовище SDK без встановлення з’єднання:

<ShellCommand prompt="user-host-machine">
sima-cli sdk setup
</ShellCommand>

Під час налаштування `sima-cli` може запропонувати вам вибрати встановлене зображення SDK, вказати каталог робочого простору хоста та налаштувати каталог розширень SDK. Під час налаштування `--devkit` також запитуються дані для підключення до DevKit і налаштовується DevKit Sync.

## Відкрийте оболонку SDK.

Після успішного завершення налаштування відкрийте командний рядок SDK:

<ShellCommand prompt="user-host-machine">
sima-cli sdk neat
</ShellCommand>

## Сумісність

SDK 2.0.0 призначений для програмного забезпечення DevKit версії 2.0.0. SDK 2.1.2 і 2.1.2.1 призначені для програмного забезпечення DevKit версії 2.1.2. Щоб отримати актуальну інформацію про сумісність, див. [Сумісність](/getting-started/compatibility/).
