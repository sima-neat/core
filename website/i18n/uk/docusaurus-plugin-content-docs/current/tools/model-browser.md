# Model Browser

[Palette Model Browser](https://developer.sima.ai/models/) містить перелік моделей, які SiMa.ai компілює та вимірює для Modalix. Сторінка кожної моделі показує продуктивність і точність, виміряні на Modalix DevKit, і пропонує скомпільовану модель для завантаження.

Використовуйте його, коли потрібно:

- знайти модель для вашого завдання, наприклад для виявлення об’єктів або генерування тексту
- порівняти продуктивність і точність моделей та їхніх варіантів
- завантажити скомпільовану модель, готову до запуску з Neat
- самостійно перезібрати модель з її публічних скриптів

## Завантаження моделі за допомогою sima-cli

`sima-cli` надає доступ до тих самих моделей із термінала. Обліковий запис не потрібен.

Знайдіть модель:

```bash
sima-cli models list -q rf_detr_nano
```

Виберіть модель, а потім варіант. Варіант – це один зі способів компіляції моделі, названий за розрядністю її ваг і активацій. Команда показує картку моделі з виміряними точністю та продуктивністю, а потім запитує, чи завантажувати модель.

Якщо ви знаєте ідентифікатор і варіант моделі, завантажте її безпосередньо:

```bash
sima-cli models download --id rf_detr_nano --variant w8a8_w16a16
```

Команда зберігає модель у `models/<model id>/<variant>/`. Щоб зберегти її в іншому місці, додайте `--output <folder>`.

Модель, ліцензія якої забороняє розповсюдження, завантажити не можна. Перезберіть її зі скриптів, як описано в наступному розділі.

Докладніше про команди див. у довіднику [`sima-cli models`](/tools/sima-cli/models/).

## Відтворення моделі

Кожна модель постачається зі скриптами, якими її було зібрано та виміряно, у [репозиторії models](https://github.com/sima-neat/models). Кожна модель має теку `models/<model id>/` з одним скриптом на кожен крок:

| Крок | Скрипт | Де виконується |
| --- | --- | --- |
| Експорт офіційної моделі в ONNX | `convert.py` | ваш комп’ютер |
| Квантування та компіляція | `compile.py` | Model Compiler у Palette SDK |
| Вимірювання продуктивності | `performance.py` | Modalix DevKit |
| Вимірювання точності | `accuracy.py` | Modalix DevKit |

Файл `model.yaml` у тій самій теці містить перелік варіантів, які можна зібрати, у розділі `build_profiles`, а також набори даних, потрібні для кожного кроку.

[Посібник для початку роботи](https://developer.sima.ai/models/docs/getting-started) проводить через кожен крок із командами, які можна скопіювати, і показує, як порівняти ваші результати з опублікованими.
