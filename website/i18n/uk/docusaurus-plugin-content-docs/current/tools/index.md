# Інструменти

Інструменти SiMa.ai, які ви використовуєте разом із Neat: командний рядок `sima-cli`, Model Browser, Insight та Sentinel. Про налаштування SDK див. [Palette SDK](/getting-started/dev-environment/).

Використовуйте ці інструменти для встановлення програмного забезпечення, отримання артефактів моделей, перевірки поведінки застосунків і керування типовими робочими процесами DevKit.
