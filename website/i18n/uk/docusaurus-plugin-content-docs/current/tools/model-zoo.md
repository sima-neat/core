# Model Zoo

:::warning Застаріло
Model Zoo застарів. Використовуйте [Model Browser](/tools/model-browser/), щоб знаходити, порівнювати та завантажувати моделі для Modalix.
:::

Model Zoo — це підібрана колекція попередньо скомпільованих і квантованих моделей, які готові до запуску на пристроях SiMa.

Використовуйте його, коли вам потрібно:

- оцінити точність і продуктивність моделі на апаратному забезпеченні Modalix
- уникнути ручної компіляції та квантування для відомої моделі
- почати з перевірених артефактів моделей
- вибрати моделі, зібрані для конкретної апаратної платформи

Model Zoo містить попередньо скомпільовані артефакти моделей для застосунків Neat C++ і PyNeat, за винятком моделей GenAI.

Список доступних моделей:

```bash
sima-cli modelzoo list
```

Перегляньте модель перед її завантаженням:

```bash
sima-cli modelzoo describe yolov5
```

Завантажте артефакт моделі:

```bash
sima-cli modelzoo get yolov5s
```

Назви моделей можуть відрізнятися залежно від випуску. Спочатку використовуйте команду `sima-cli modelzoo list`, якщо ви не впевнені, який ідентифікатор моделі слід використовувати.

Докладніше про команди див. у довіднику [`sima-cli modelzoo`](/tools/sima-cli/modelzoo/).

## Моделі GenAI

Для GenAI SiMa.ai надає попередньо скомпільовані колекції моделей LLM, VLM та ASR на платформі [Hugging Face](https://huggingface.co/simaai). Завантажте їх за допомогою LLiMa CLI:

```bash
llima pull <model_name>
```

Наприклад:

```bash
llima pull Qwen3-VL-4B-Instruct-GPTQ-a16w4
```

Після завантаження моделі GenAI використовуйте середовище виконання LLiMa, щоб запустити її на DevKit.
Налаштування та команди середовища виконання описано в розділі [GenAI з LLiMa](/genai-llima/).
