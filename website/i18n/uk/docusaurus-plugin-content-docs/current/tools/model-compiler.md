# Model Compiler

Model Compiler перетворює навчені моделі на готові для Modalix архіви моделей, які Neat
може завантажувати та запускати.

Використовуйте його, коли вам потрібно:

- перевірити, чи сумісна модель із платформою SiMa.ai;
- виконати квантування та компіляцію підтримуваної моделі;
- перевірити точність і продуктивність перед використанням архіву в застосунку Neat.

Покроковий робочий процес описано в розділі [Компіляція моделі](/compile-a-model/). Довідкові матеріали з API див. у розділі [Model Compiler API](/reference/model-sdk-api/).
