# Model Compiler

Model Compiler перетворює навчені моделі на архіви моделей, готові для використання в Modalix, які Neat
може завантажувати та запускати.

Використовуйте його, коли вам потрібно:

- перевірте, чи сумісна модель із платформою SiMa.ai;
- виконуйте квантування та компіляцію підтримуваної моделі;
- перевірте точність і продуктивність перед використанням архіву в застосунку Neat.

Для організації робочого процесу почніть з [Складіть модель.](/compile-a-model/). Для отримання довідкової інформації щодо API див. [Model Compiler API.](/reference/model-sdk-api/).
