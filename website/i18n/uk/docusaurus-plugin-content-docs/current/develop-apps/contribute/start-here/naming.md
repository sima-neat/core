# Контракт іменування

Цей документ визначає канонічний контракт іменування для кодової бази SiMa.ai Neat.

## Канонічні назви

- Назва продукту: `SiMa.ai Neat`
- Проєкт CMake: `SimaNeat`
- Простір імен C++: `simaai::neat`
- Основні типи середовища виконання: `Model`, `Graph`, `Run`

## Публічні заголовні файли

Використовуйте заголовні файли в `include/` як публічне джерело істини.

Приклади:

```cpp
#include "model/Model.h"
#include "pipeline/Graph.h"
#include "pipeline/Run.h"
```

## Застарілі псевдоніми

Застарілі назви підтримуються лише для довідки щодо сумісності та в посібниках з міграції.

- `PipelineSession` -> `Graph`
- `PipelineRun` -> `Run`
- `NeatModel` -> `Model`
- `InputAppSrc` -> `Input`
- `OutputAppSink` -> `Output`

Не додавайте нових публічних документів чи прикладів із застарілими символами.

## Політика

- Нова документація для користувачів має використовувати канонічні назви.
- Застарілі терміни дозволені лише в примітках щодо міграції, коментарях щодо сумісності або
  чітко позначених розділах про виведення з ужитку.
- CI забезпечує дотримання цього правила за допомогою `scripts/ci/check_naming_and_conflicts.sh`.
