# Модель GenAI

Neat використовує GenAI API для моделей LLM, VLM та ASR, підготовлених за допомогою LLiMa. Для генеративних моделей ці API є відповідником
[`Model`](/develop-apps/development-workflow/model): завантажте теку розгорнутої моделі, створіть запит, а потім виконайте його у своєму застосунку або обслуговуйте модель через HTTP. Для застосунків на хост-машині, підключеній до PCIe-карти Modalix, використовуйте [GenAI API через PCIe](/develop-apps/development-workflow/genai-model/pcie-api).

Використовуйте ці API, коли ваш застосунок звертається до моделі, щоб згенерувати текст, відповісти на запитання щодо зображень, викликати інструменти або транскрибувати аудіо. Для дискримінативних моделей із фіксованою формою входів, як-от моделі класифікації, виявлення, сегментації або ембедингів, використовуйте класичний API `Model`.

## Місце GenAI у Neat

Шлях GenAI має таку ж загальну структуру, як і решта компонентів Neat:

1. Підготуйте або завантажте артефакт моделі для Modalix.
2. Розмістіть модель на цільовому пристрої, зазвичай у теці `/media/nvme/llima/models/`, або залиште її на хості для виконання через PCIe.
3. Завантажте модель зі свого застосунку на C++ або Python.
4. Надсилайте запит безпосередньо або надавайте доступ до моделі через `GenAIServer`.
5. Перегляньте повний результат або використовуйте потоковий вивід.

LLiMa відповідає за підготовку моделей GenAI, тестування з командного рядка та бенчмаркінг.
Neat відповідає за API для застосунків та інтеграцію із середовищем виконання, щойно модель використовується у вашому застосунку. Докладніше про підготовку моделей див. у розділі [GenAI з LLiMa](/genai-llima/).

Використовуйте прямі виклики для вбудованої логіки застосунку та тестів, які мають виконуватися в одному процесі з моделлю. Використовуйте сервер, коли клієнти не повинні компонуватися із середовищем виконання Neat або коли один процес має маршрутизувати запити до кількох обслуговуваних моделей.

## Наступні кроки

- Запускайте моделі з хоста за допомогою [GenAI API через PCIe](/develop-apps/development-workflow/genai-model/pcie-api).
- Повний приклад HTTP-сервера наведено в посібнику [Обслуговування моделей GenAI](/tutorials/serve-genai-models).
- Покрокову інструкцію для запуску в межах процесу наведено в посібнику [Запуск LLM через прямий API](/tutorials/run-an-llm).
- Підготовку та бенчмаркінг моделей описано в розділі [GenAI з LLiMa](/genai-llima/).
