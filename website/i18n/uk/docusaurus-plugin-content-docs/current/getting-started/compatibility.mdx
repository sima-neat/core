# Сумісність

:::tip Налаштовуєте вперше?
Ця сторінка — **довідник** із сумісності версій, а не крок налаштування.

Стандартне встановлення SDK уже встановлює сумісні типові версії. Щоб виконати налаштування вперше, спочатку з’ясуйте версію програмного забезпечення DevKit, а потім перегляньте сторінку [Palette SDK](/getting-started/dev-environment/), зокрема її розділ [вимоги до хоста](/getting-started/dev-environment/#host-requirements). Використовуйте таблиці нижче лише для того, щоб зафіксувати версії, поєднати компоненти з різних версій прошивки або діагностувати невідповідність.
:::

Використовуйте цю сторінку як довідник, коли потрібно вибрати точні версії, оновити один компонент окремо від інших, усунути невідповідність версій або підготувати випуск. Якщо ви налаштовуєте Palette SDK уперше, почніть зі сторінок Palette SDK і Neat Library. Описані там процедури встановлюють підтримувані типові комбінації.

Palette SDK складається з кількох версійованих компонентів. Здебільшого сумісність зводиться до двох правил:

1. **Neat Library** і **Palette SDK** мають бути сумісними
   з версією програмного забезпечення DevKit, на якій вони працюють або для якої виконується збирання.
2. **Model Compiler** має бути сумісним із **Palette SDK**
   або середовищем хоста, у якому його встановлено.

Кожна серія випусків Palette SDK орієнтована на певну версію програмного забезпечення DevKit. Патч-ревізії SDK можуть додавати виправлення інструментів, не вимагаючи нового образу DevKit.
Наприклад, випуски Palette SDK 2.1.3.x, зокрема 2.1.3.0, сумісні з програмним забезпеченням DevKit 2.1.3.

Ви також можете встановити новішу сумісну Neat Library без перевстановлення SDK, якщо використовуєте комбінацію, наведену в таблиці нижче. Наприклад, використовуйте Neat Library 0.6.2 з Palette SDK 3.0.0.2.

:::note
У таблицях наведено й історичні комбінації версій. Статус підтримки випусків дивіться у стовпці «Примітки» таблиці Neat Library.
:::

## DevKit

Кожен Modalix DevKit постачається з певною версією програмного забезпечення DevKit. Перевірте цю версію, перш ніж вибирати версію Palette SDK або Neat Library.

Таблиці сумісності нижче впорядковано за версією програмного забезпечення DevKit, оскільки середовище виконання на пристрої, прошивка та системні пакети встановлюються як узгоджений набір.

Отримавши доступ до оболонки DevKit, перевірте встановлену версію програмного забезпечення. Відкрити оболонку можна через SSH, якщо DevKit доступний у мережі, або через послідовну консоль. Інструкції щодо доступу через послідовний порт див. у розділі [Налаштування послідовного доступу](https://developer.sima.ai/hardware/getting-started/setup-serial).

<ShellCommand prompt="devkit">
cat /etc/buildinfo
</ShellCommand>

Якщо версія програмного забезпечення DevKit несумісна з версією Neat Library, яку ви намагаєтеся встановити, `sima-cli neat install` блокує встановлення, а не поєднує несумісні компоненти середовища виконання на пристрої. У такому разі або встановіть версію Neat Library, що підтримує поточне програмне забезпечення DevKit, або спочатку оновіть прошивку DevKit.

Інструкції щодо перевірки та оновлення прошивки DevKit див. у розділі [Оновлення прошивки](https://developer.sima.ai/hardware/getting-started/firmware-update).

## Palette SDK

Використовуйте цю таблицю, щоб перевірити, чи відповідає Palette SDK версії програмного забезпечення вашого DevKit.

| Palette SDK | Сумісне середовище хоста | Сумісне програмне забезпечення DevKit |
| :--- | :--- | :--- |
| **2.0.0** | Windows 11 через WSL, Ubuntu 22.04 або 24.04, остання версія macOS на Apple Silicon | **2.0.0** |
| **2.1.2.3** | Windows 11 через WSL, Ubuntu 22.04 або 24.04, остання версія macOS на Apple Silicon | **2.1.2** |
| **2.1.3.0** | Windows 11 через WSL, Ubuntu 22.04 або 24.04, остання версія macOS на Apple Silicon | **2.1.3** |
| **2.1.3.1** | Windows 11 через WSL, Ubuntu 22.04 або 24.04, остання версія macOS на Apple Silicon | **2.1.3** |
| **3.0.0.0** | Windows 11 через WSL, Ubuntu 22.04 або 24.04, остання версія macOS на Apple Silicon | **3.0.0** |
| **3.0.0.1** | Windows 11 через WSL, Ubuntu 22.04 або 24.04, остання версія macOS на Apple Silicon | **3.0.0** |
| **3.0.0.2** | Windows 11 через WSL, Ubuntu 22.04 або 24.04, остання версія macOS на Apple Silicon | **3.0.1** |

Встановіть точну версію SDK, сумісну з програмним забезпеченням вашого DevKit. Наприклад, щоб установити Palette SDK 3.0.0.2 для програмного забезпечення DevKit 3.0.1, виконайте на хості:

<ShellCommand prompt="host">
sima-cli neat install sdk@v3.0.0.2
</ShellCommand>

Точні теги та канали випусків див. у розділі [Встановлення певної версії SDK](/getting-started/dev-environment/install-the-environment/#install-a-specific-sdk-version).

Лише SDK 2.0.0, 2.1.2.0 і 2.1.2.1 потребують [двоетапного встановлення SDK](/reference/two-step-sdk-installation/).

## Neat Library

Використовуйте цю таблицю, щоб вибрати версію Neat Library, яку потрібно встановити або оновити у вашому
Palette SDK і на вашому DevKit.

| Neat Library | Сумісний Palette SDK | Сумісне програмне забезпечення DevKit | Примітки |
| :--- | :--- | :--- | :--- |
| **0.1.0** | **2.0.0** | **2.0.0** | Підтримку припинено. |
| **0.2.2** | **2.1.2.2** | **2.1.2** | Підтримку припинено. |
| **0.3.0** | **2.1.2.3** | **2.1.2** | Підтримку припинено. |
| **0.4.0** | **2.1.3.0** | **2.1.3** | Підтримку припинено. |
| **0.5.0** | **2.1.3.1** | **2.1.3** | Підтримуваний випуск. |
| **0.6.0** | **3.0.0.0** | **3.0.0** | Підтримуваний випуск. |
| **0.6.1** | **3.0.0.1** | **3.0.0** | Підтримуваний випуск. |
| **0.6.2** | **3.0.0.2** | **3.0.1** | Поточний випуск. |

Версія програмного забезпечення DevKit має значення, оскільки середовище виконання на пристрої, прошивка та системні пакети встановлюються як узгоджений набір. Якщо поєднувати компоненти з різних версій прошивки, можлива непередбачувана поведінка, навіть коли ваш застосунок успішно збирається.

Зазвичай ці команди не потрібно виконувати під час первинного налаштування — SDK сам встановлює сумісну Neat Library. Використовуйте їх лише для того, щоб зафіксувати певну версію Neat Library всередині сумісного Palette SDK або безпосередньо на DevKit.

Для Neat Library 0.6.1:

<ShellCommand prompt="sdk|devkit">
sima-cli neat install core@v0.6.1
</ShellCommand>

Щоб зафіксувати Neat Library 0.6.2 на DevKit із Platform 3.0.1:

<ShellCommand prompt="devkit">
sima-cli neat install core@v0.6.2
</ShellCommand>

Для Neat Library 0.1.0:

<ShellCommand prompt="sdk|devkit">
sima-cli neat install core@v0.1.0
</ShellCommand>

## Model Compiler

Model Compiler потрібен, коли ви самостійно компілюєте або квантуєте моделі, зокрема моделі GenAI, і він необов’язковий лише тоді, коли ви використовуєте виключно попередньо скомпільовані пакети моделей. Звертайтеся до цієї таблиці, коли він вам потрібен.

Model Compiler можна встановити двома способами:

- всередині сумісного Palette SDK. У цьому режимі можна використовувати будь-яку ОС хоста,
  яку підтримує ця версія Palette SDK. Саме цей шлях
  описано в розділі
  [Встановлення Model Compiler](/getting-started/dev-environment/install-model-compiler/).
- безпосередньо на підтримуваній хост-машині або віртуальній машині з Ubuntu. У цьому режимі ОС хоста
  має відповідати вимогам Model Compiler до хоста, наведеним нижче. Команди встановлення див. у розділі
  [Встановлення Model Compiler](/getting-started/dev-environment/install-model-compiler/).

Під час встановлення або налаштування SDK процес налаштування пропонує автоматично встановити відповідну версію Model Compiler, якщо вона доступна для вашого середовища.

| Model Compiler | Сумісний Palette SDK | Сумісне середовище хоста | Примітки |
| :--- | :--- | :--- | :--- |
| **2.0.0** | **2.0.0** | Ubuntu 22.04 `x86_64` | Apple Silicon і aarch64/Linux не підтримуються. |
| **2.1.2** | **2.1.2.3** | Ubuntu 24.04 `x86_64` / `aarch64` | Apple Silicon підтримується через встановлення всередині Palette SDK. |
| **2.1.3** | **2.1.3.0** | Ubuntu 24.04 `x86_64` / `aarch64` | Apple Silicon підтримується через встановлення всередині Palette SDK. |
| **2.1.3.1** | **2.1.3.1** | Ubuntu 24.04 `x86_64` / `aarch64` | Apple Silicon підтримується через встановлення всередині Palette SDK. |
| **3.0.0** | **3.0.0.0** | Ubuntu 24.04 `x86_64` / `aarch64` | Apple Silicon підтримується через встановлення всередині Palette SDK. |
| **3.0.0.1** | **3.0.0.1** | Ubuntu 24.04 `x86_64` / `aarch64` | Apple Silicon підтримується через встановлення всередині Palette SDK. |

Стовпець «Сумісне середовище хоста» стосується окремих встановлень Model Compiler. Наприклад, клієнт із хостом Ubuntu 22.04 усе одно може використовувати Model Compiler 2.1.3, встановивши його всередині Palette SDK 2.1.3.0, оскільки Palette SDK надає сумісне контейнерне середовище на базі Ubuntu 24.04.

Кроки встановлення див. у розділі
[Встановлення Model Compiler](/getting-started/dev-environment/install-model-compiler/).

## Перевірка версій

Усередині Palette SDK або на DevKit виконайте:

<ShellCommand prompt="sdk|devkit">
neat
</ShellCommand>

Наведений нижче приклад виводу показує активне середовище, версію Palette SDK, версії встановлених компонентів і наявність оновлень:

```text
Neat Environment
  Mode               Palette SDK
  SDK Version        3.0.0_Palette_SDK_neat_v3.0.0.1
  Platform Version   3.0.0
  Sysroot            /opt/toolchain/aarch64/modalix
  Update check       online

Components
  Neat core              0.6.1 channel=release env=prod latest=0.6.1
  PyNeat                 0.6.1
  neat-runtime           0.6.1
  neat-gst-plugins       0.6.1
  neat-llima             0.6.1
  neat-insight           0.0.9 channel=release status=Running venv=/opt/neat-insight/venv
  Model Compiler         not installed

  Update available: yellow component versions indicate available updates.
  Run: neat update.
```

За цим виводом переконайтеся, що ваші Neat Library, програмне забезпечення DevKit і необов’язковий Model Compiler належать до підтримуваної комбінації версій.
