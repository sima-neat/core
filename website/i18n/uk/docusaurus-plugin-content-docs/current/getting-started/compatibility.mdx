# Сумісність

:::tip Налаштовуєте вперше?
Ця сторінка є довідником щодо сумісності версій, а не інструкцією з налаштування.

Під час стандартної інсталяції SDK автоматично встановлюються сумісні параметри за замовчуванням. Щоб налаштувати систему вперше, спочатку дізнайтеся версію програмного забезпечення DevKit, а потім перевірте [Neat SDK](/getting-started/dev-environment/), зокрема її [вимоги до хоста](/getting-started/dev-environment/#host-requirements). Використовуйте таблиці нижче лише для фіксації версій, поєднання компонентів між різними версіями прошивки або для виявлення невідповідностей.
:::

Використовуйте цю сторінку як довідник, коли вам потрібно вибрати конкретні версії, оновити окремий компонент, усунути проблеми, пов’язані з несумісністю версій, або підготувати випуск. Якщо ви налаштовуєте Palette Neat вперше, почніть зі сторінок Neat Development Environment (далі – Neat SDK) та Neat Library. Ці інструкції встановлюють підтримувані стандартні комбінації.

Palette Neat містить кілька компонентів, для яких передбачено різні версії. У більшості випадків сумісність визначається двома правилами:

1. **Neat Library** і **Neat SDK** повинні бути сумісними між собою.
   з використанням версії програмного забезпечення DevKit, для якої вони розроблені або з якою вони сумісні.
2. **Model Compiler** має бути сумісним із **Neat SDK**.
   або середовище хоста, де воно встановлено.

Кожна серія випусків Neat SDK призначена для певної версії програмного забезпечення DevKit. Оновлення, що містять виправлення, у SDK можуть додавати виправлення інструментів без необхідності створення нового образу DevKit.
Наприклад, випуски Neat SDK 2.1.2.x, включно з 2.1.2.3, сумісні з програмним забезпеченням DevKit 2.1.2.

Ви також можете встановити новішу сумісну версію Neat Library без повторного встановлення SDK, якщо ви використовуєте комбінацію, наведену в таблиці нижче. Наприклад, використовуйте Neat Library 0.3.0 з Neat SDK 2.1.2.3.

:::note
Версії, перелічені на цій сторінці, є підтримуваними комбінаціями версій.
:::

## DevKit

Кожен комплект Modalix DevKit постачається з певною версією програмного забезпечення DevKit. Перевірте цю версію, перш ніж вибирати версію Neat SDK або Neat Library.

У таблицях сумісності, наведених нижче, версії програмного забезпечення DevKit є ключовими, оскільки середовище виконання, прошивка та системні пакети, що встановлюються на пристрій, встановлюються як узгоджений набір.

Після отримання доступу до командного рядка DevKit, перевірте встановлену версію програмного забезпечення. Ви можете відкрити командний рядок через SSH, коли DevKit доступний у мережі, або через послідовну консоль. Інструкції щодо послідовного доступу див. у розділі [Налаштуйте послідовний доступ.](https://developer.sima.ai/hardware/getting-started/setup-serial).

<ShellCommand prompt="modalix">
cat /etc/buildinfo
</ShellCommand>

Якщо версія програмного забезпечення DevKit несумісна з версією Neat Library, яку ви намагаєтеся встановити, `sima-cli neat install` блокує встановлення, замість того, щоб поєднувати несумісні компоненти середовища виконання на пристрої. У цьому випадку або встановіть версію Neat Library, яка підтримує поточну версію програмного забезпечення DevKit, або спочатку оновіть прошивку DevKit.

Інструкції щодо перевірки та оновлення прошивки DevKit див. у розділі [Оновлення програмного забезпечення](https://developer.sima.ai/hardware/getting-started/firmware-update).

## Neat SDK

Використовуйте цю таблицю, щоб перевірити, чи відповідає версія Neat SDK версії вашого програмного забезпечення DevKit.

| Neat SDK | Сумісне середовище хоста. | Сумісне програмне забезпечення DevKit. |
| :--- | :--- | :--- |
| **2.0.0** | Windows 11 за допомогою WSL, Ubuntu 22.04 або 24.04, остання версія macOS для процесорів Apple Silicon. | **2.0.0** |
| **2.1.2.3** | Windows 11 за допомогою WSL, Ubuntu 22.04 або 24.04, остання версія macOS для процесорів Apple Silicon. | **2.1.2** |

Встановіть поточну версію Neat SDK, завантаживши її з хосту:

<ShellCommand prompt="user-host-machine">
sima-cli neat install sdk@release-2.1
</ShellCommand>

Наразі пакет `release-2.1` SDK відповідає версії Neat SDK 2.1.2.3. Він
залишається сумісним із програмним забезпеченням DevKit версії 2.1.2.

Використовуйте старішу версію Neat SDK лише в тому випадку, якщо ваше програмне забезпечення DevKit використовує саме цю версію прошивки. Для SDK версій 2.0.0, 2.1.2.0 або 2.1.2.1 використовуйте
[Двохетапна інсталяція SDK](/reference/two-step-sdk-installation/).

## Neat Library

Використовуйте цю таблицю, щоб обрати версію Neat Library, яку потрібно встановити або оновити у вашому
Neat SDK та на вашому DevKit.

| Neat Library | Сумісний з Neat SDK. | Сумісне програмне забезпечення DevKit. | Примітки |
| :--- | :--- | :--- | :--- |
| **0.1.0** | **2.0.0** | **2.0.0** | Підтримується для прошивки версії 2.0. |
| **0.2.2** | **2.1.2.2** | **2.1.2** | Остання версія 0.2. |
| **0.3.0** | **2.1.2.3** | **2.1.2** | Остання актуальна версія. |

Версія програмного забезпечення DevKit має значення, оскільки середовище виконання, прошивка та системні пакети встановлюються як сумісний набір. Якщо ви змішуєте компоненти між різними версіями прошивки, можуть виникнути непередбачувані проблеми, навіть якщо ваша програма успішно компілюється.

Зазвичай, ці команди не виконуються під час первинного налаштування — SDK встановлює сумісну Neat Library для вас. Використовуйте їх лише для фіксації певної версії Neat Library зсередини сумісного Neat SDK або безпосередньо на DevKit.

Для Neat Library 0.3.0:

<ShellCommand prompt="sdk-or-devkit">
sima-cli neat install core@v0.3.0
</ShellCommand>

Для Neat Library 0.1.0:

<ShellCommand prompt="sdk-or-devkit">
sima-cli neat install core@v0.1.0
</ShellCommand>

## Model Compiler

Model Compiler необхідний, коли ви самостійно компілюєте або квантуєте моделі, зокрема моделі GenAI, і є необов’язковим лише в тому випадку, якщо ви використовуєте виключно попередньо скомпільовані пакети моделей. Використовуйте цю таблицю, коли він вам знадобиться.

Model Compiler можна встановити двома способами:

- всередині сумісного Neat SDK. У цьому режимі використовуйте будь-який хост.
  Операційні системи, які підтримуються цією версією Neat SDK. Це шлях, описаний у
[Встановіть Model Compiler.](/getting-started/dev-environment/install-model-compiler/).
- безпосередньо на підтримуваній машині або віртуальній машині з операційною системою Ubuntu. У цьому режимі операційна система хоста.
  повинна відповідати вимогам до хосту Model Compiler, зазначеним нижче. Див.
[Встановіть Model Compiler.](/getting-started/dev-environment/install-model-compiler/) для команд встановлення.

Під час встановлення/налаштування SDK процес налаштування пропонує автоматично встановити відповідну версію Model Compiler, якщо така доступна для вашого середовища.

| Model Compiler | Сумісний з Neat SDK. | Сумісне середовище хоста. | Примітки |
| :--- | :--- | :--- | :--- |
| **2.0.0** | **2.0.0** | Ubuntu 22.04 `x86_64` | Відсутня підтримка Apple Silicon або aarch64/Linux. |
| **2.1.2** | **2.1.2.3** | Ubuntu 24.04 `x86_64` / `aarch64`. | Підтримка Apple Silicon реалізується шляхом встановлення всередині Neat SDK. |

Стовпець «середовище хоста» стосується окремих інсталяцій Model Compiler. Наприклад, клієнт, який використовує хост Ubuntu 22.04, все ще може використовувати Model Compiler 2.1.2, встановивши його в Neat SDK 2.1.2.3, оскільки Neat SDK надає сумісне контейнерне середовище на базі Ubuntu 24.04.

Інструкції щодо встановлення див. у розділі [Встановіть Model Compiler.](/getting-started/dev-environment/install-model-compiler/).

## Перевірте версії.

Усередині Neat SDK або на DevKit виконайте команду:

<ShellCommand prompt="sdk-or-devkit">
neat
</ShellCommand>

Наведений нижче приклад виводу показує активне середовище, версію Neat SDK, версії встановлених компонентів і наявність доступних оновлень:

```text
Neat Environment
  Mode               Neat SDK
  SDK Version        2.1.2_Palette_SDK_neat_v2.1.2.3
  Platform Version   2.1.2
  Sysroot            /opt/toolchain/aarch64/modalix
  Update check       online

Components
  Neat core              0.3.0 channel=release env=prod latest=0.3.0
  PyNeat                 0.3.0
  neat-runtime           0.3.0
  neat-gst-plugins       0.3.0
  neat-llima             0.3.0
  neat-insight           0.0.6 channel=release status=Running venv=/opt/neat-insight/venv
  Model Compiler         not installed

  Update available: yellow component versions indicate available updates.
  Run: neat update.
```

Використовуйте ці дані, щоб переконатися, що ваше програмне забезпечення Neat Library, DevKit і додатковий компонент Model Compiler належать до сумісної версії.
