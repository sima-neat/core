Використовуйте цю сторінку для встановлення або оновлення Palette Neat Library.

:::tip Neat Library у складі Neat SDK.
Під час підключення DevKit під час налаштування `sima-cli sdk setup`, SDK автоматично встановлює Neat Library, що входить до комплекту, та пов’язане з нею середовище PyNeat у `~/pyneat` на DevKit.
:::

## Оберіть місце встановлення.

Запустіть програму встановлення в тому середовищі, де ви створюєте або запускаєте програми Neat:

| Середовище | Використовуйте це, коли |
| --- | --- |
| Neat SDK | Ви хочете оновити Neat Library у Neat SDK без встановлення нової версії SDK. |
| ROS2 SDK | Ви хочете скомпілювати програми ROS 2 безпосередньо на платформі ARM64, використовуючи заголовки та бібліотеки Neat, встановлені в системних шляхах контейнера. |
| DevKit | Ви хочете встановити або оновити середовище виконання безпосередньо на пристрої. |

## Необхідні умови

Встановіть `sima-cli` в середовищі, де ви плануєте встановити Neat Library.
Використовуйте [інструкція зі встановлення sima-cli](/tools/sima-cli/).

Створіть обліковий запис на [community.sima.ai](https://community.sima.ai), щоб отримати доступ до ресурсів SiMa.ai, таких як попередньо скомпільовані моделі для тестування.

Авторизуйте середовище, щоб програма встановлення могла завантажити артефакти SiMa.ai. Детальніше див. у [sima-cli вхід](/tools/sima-cli/login/).

<ShellCommand prompt="sdk|devkit">
sima-cli login
</ShellCommand>

Підтвердьте, чи може середовище отримати доступ до хоста, де розміщено SiMa.ai, та до артефактів:

<ShellCommand prompt="sdk|devkit">
curl -fsS https://artifacts.neat.sima.ai/sima-cli/linux-mac.sh -o /dev/null && echo "artifacts reachable"
</ShellCommand>

Виведення повідомлення про те, що `artifacts reachable`, означає, що до хоста можна отримати доступ. Помилка `curl`, наприклад, через перевищення часу очікування, відмову в підключенні або повідомлення «не вдалося визначити хост», означає, що вихідний доступ заблоковано — перевірте мережу хоста, проксі-сервер або брандмауер (див. [Neat SDK Мережеві можливості.](/tools/sima-cli/sdk-networking/) та [нотатки щодо налаштування хоста](/reference/elxr-sdk-host-setup/ubuntu)) або використовуйте [Встановлення в автономному режимі](/getting-started/dev-environment/offline-installation), якщо машина не може безпосередньо отримати доступ до служб SiMa.ai.

## Встановіть Neat Library.

:::note Сумісність пакетів
Програма встановлення використовує всі пакети Debian, перелічені у вибраному основному артефакті, і не вибирає інші версії внутрішніх компонентів або LLiMa. Встановлена платформа повинна задовольняти залежностям, які не містяться в цьому артефакті. Якщо APT видалятиме пакети платформи для завершення встановлення, програма встановлення зупиняється; замість цього оновіть платформу, а не замінюйте пакети в основному артефакті або LLiMa.
:::

Оберіть робочу директорію перед запуском інсталятора. На DevKit встановіть програмне забезпечення в `/media/nvme`, щоб уникнути заповнення кореневої файлової системи. У контейнері SDK використовуйте локальний для контейнера шлях, наприклад `$HOME/neat`.

Оберіть потрібне середовище, а потім виконайте кроки в зазначеному порядку. Встановіть у контейнері **Neat SDK**, щоб здійснити перехресну компіляцію програм C++. Встановіть у **ROS2 SDK**, щоб здійснити компіляцію безпосередньо на ARM64; його пакети Debian встановлюються в `/usr`, а не в системну директорію перехресної компіляції Neat. Встановіть на **DevKit**, щоб налаштувати середовище виконання, яке також забезпечує наявність PyNeat у `~/pyneat`. Команда інсталятора однакова в кожному середовищі.

<CodeTabs>
<CodeTab label="Neat SDK" lang="bash">

Підготуйте локальну директорію для встановлення контейнера, наприклад, `$HOME/neat`:

<ShellCommand prompt="sdk">
cd $HOME && mkdir -p neat && cd neat
</ShellCommand>

Встановіть стандартний пакет Neat Library, обраний за допомогою `sima-cli`. За бажанням, ви можете встановити додаткові компоненти, зокрема попередньо підготовлені навчальні матеріали, навчальні матеріали з кодом і тести:

<ShellCommand prompt="sdk">
sima-cli neat install core@v0.4.0
</ShellCommand>

</CodeTab>

<CodeTab label="ROS2 SDK" lang="bash">

Підтвердіть, що контейнер ідентифікує себе як нативний SDK ROS2 і повідомляє про базову сумісність платформи, необхідну для пакета Neat:

<ShellCommand prompt="sdk">
grep -E '^(SDK Type|Platform Base|Platform Version) =' /etc/sdk-release
</ShellCommand>

Встановіть сумісний пакет Neat. Програма встановлення перевіряє нативне середовище Debian для ARM64, імітує транзакцію APT із вимкненою опцією видалення пакетів і встановлює середовище виконання та пакети для розробки в системні шляхи контейнера. PyNeat не встановлюється, оскільки він залишається функцією середовища виконання DevKit:

<ShellCommand prompt="sdk">
cd $HOME &amp;&amp; mkdir -p neat &amp;&amp; cd neat
sima-cli neat install core@release-0.3
</ShellCommand>

</CodeTab>

<CodeTab label="DevKit" lang="bash">

:::note Спочатку оновіть прошивку DevKit.
Перш ніж встановлювати Neat Library на DevKit, переконайтеся, що версія програмного забезпечення DevKit сумісна з Neat Library. Додаткову інформацію див. у
[Посібник зі сумісності](/getting-started/compatibility/).
:::

Підготуйте каталог для встановлення в `/media/nvme`, щоб уникнути заповнення кореневої файлової системи:

<ShellCommand prompt="devkit">
cd /media/nvme && mkdir -p neat && cd neat
</ShellCommand>

Встановіть стандартний пакет Neat Library, обраний за допомогою `sima-cli`. За бажанням, ви можете встановити додаткові компоненти, зокрема попередньо підготовлені навчальні матеріали, навчальні матеріали з кодом і тести:

<ShellCommand prompt="devkit">
sima-cli neat install core@v0.2.2
</ShellCommand>

</CodeTab>
</CodeTabs>

## Стандартне середовище PyNeat.

Встановлення Neat Library на DevKit також передбачає створення стандартного віртуального середовища PyNeat у `~/pyneat` на DevKit. Це підтримуване середовище PyNeat — активуйте його безпосередньо:

<ShellCommand prompt="devkit">
source ~/pyneat/bin/activate
</ShellCommand>

Якщо ви запускаєте програму встановлення всередині контейнера SDK, пов’язаного з DevKit Sync, програма встановлення розгортає PyNeat на пов’язаному DevKit, а не лише всередині контейнера SDK. PyNeat встановлюється у віртуальне середовище під `~/pyneat` на DevKit.

Інформацію про налаштування власних віртуальних середовищ Python див. у розділі [Встановіть PyNeat.](/getting-started/neat-library/pyneat/).

## Збірки з вихідного коду

Збирайте проєкт із вихідного коду, коли вам потрібна непублікована зміна, спеціальна конфігурація збірки або коли ви робите внесок у Neat Library. Більшості користувачів слід використовувати попередньо зібраний пакет, наведений вище.

Якщо ви віддаєте перевагу збірці з вихідного коду, дотримуйтесь інструкцій у
[Створити](/develop-apps/contribute/build).

Інформацію про налаштування SDK і початок роботи з DevKit Sync можна знайти в
[Neat SDK](/getting-started/dev-environment/).

## Наступний крок

Продовжуйте встановлення [Встановіть PyNeat.](/getting-started/neat-library/pyneat/), щоб налаштувати власне середовище Python, або використовуйте [Neat CLI](/getting-started/neat-library/neat-cli/) для перевірки встановленого середовища.
