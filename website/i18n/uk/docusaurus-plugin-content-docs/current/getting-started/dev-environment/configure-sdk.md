:::tip Починайте тут, лише якщо змінюєте налаштування SDK
Команда встановлення SDK уже завантажує образ SDK і налаштовує його. Користуйтеся цією сторінкою, якщо потрібно змінити налаштування SDK, як-от розташування робочого простору, під’єднання DevKit, розширення SDK або інші параметри налаштування.
:::

Запускайте `sima-cli sdk setup` безпосередньо, коли потрібно налаштувати наявний контейнер Neat SDK.

## Налаштування з під’єднанням DevKit

Використовуйте цю команду, коли DevKit доступний із хоста і ви хочете додати або оновити під’єднання DevKit:

<ShellCommand prompt="host">
sima-cli sdk setup --devkit {devkit-ip}
</ShellCommand>

Підготуйте:

- IP-адресу DevKit;
- пароль адміністратора хоста, якщо потрібно встановити або налаштувати NFS;
- облікові дані користувача DevKit, які потрібно ввести на запит. Користувач за замовчуванням — `sima`,
  пароль за замовчуванням — `edgeai`.

З `--devkit` налаштування вмикає DevKit Sync. Воно експортує робочий простір хоста через NFS і за замовчуванням монтує його на DevKit як `/workspace`.

## Налаштування без під’єднання DevKit

Використовуйте цю команду, коли потрібно оновити налаштування SDK, а DevKit ще недоступний:

<ShellCommand prompt="host">
sima-cli sdk setup
</ShellCommand>

Під час налаштування `sima-cli` може попросити вас:

- вибрати теку робочого простору на хості. Залиште значення за замовчуванням, якщо вам не потрібен
  інший робочий простір;
- вибрати теку для розширень SDK;
- вирішити, чи встановлювати Model Compiler.

Model Compiler потрібен, щоб самостійно компілювати або квантувати моделі, і необов’язковий, лише якщо ви використовуєте виключно попередньо скомпільовані пакети моделей. Встановіть його тут, якщо плануєте компілювати або квантувати моделі, і виконайте `sima-cli login`, якщо з’явиться запит.
