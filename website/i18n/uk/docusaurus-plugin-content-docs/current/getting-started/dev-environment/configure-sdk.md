:::tip Починайте звідси лише під час зміни налаштувань SDK.
Команда встановлення SDK вже завантажує образ SDK і налаштовує його. Використовуйте цю сторінку, якщо вам потрібно змінити налаштування SDK, наприклад, розташування робочого простору, DevKit підключення, розширення SDK або інші параметри налаштування.
:::

Запустіть `sima-cli sdk setup` безпосередньо, коли вам потрібно налаштувати наявний контейнер SDK Neat.

## Налаштуйте з’єднання за допомогою DevKit.

Використовуйте цю команду, коли до вашого DevKit можна отримати доступ з хоста, і ви хочете додати або оновити пару DevKit:

<ShellCommand prompt="host">
sima-cli sdk setup --devkit {devkit-ip}
</ShellCommand>

Підготуйте наступне:

- IP-адреса DevKit;
- ваш пароль адміністратора хоста, якщо потрібно встановити або налаштувати NFS;
- введіть облікові дані користувача DevKit, коли буде запропоновано. Облікові дані користувача за замовчуванням: `sima`.
  пароль за замовчуванням — `edgeai`.

За допомогою `--devkit` налаштування дає змогу використовувати DevKit Sync. Воно експортує робочий простір хоста через NFS і за замовчуванням монтує його як `/workspace` на DevKit.

## Налаштуйте без використання функції DevKit для створення пари.

Використовуйте цю команду, коли потрібно оновити налаштування SDK, але DevKit ще недоступний:

<ShellCommand prompt="host">
sima-cli sdk setup
</ShellCommand>

Під час налаштування `sima-cli` може запропонувати вам виконати наступні дії:

- оберіть каталог робочого простору хоста. Залиште значення за замовчуванням, якщо у вас немає особливих потреб.
  різні робочі простори;
- оберіть каталог для розширень SDK;
- обирайте, чи встановлювати Model Compiler.

Для самостійного компілювання або квантування моделей необхідний Model Compiler. Він є необов’язковим лише в тому випадку, якщо ви використовуєте виключно попередньо скомпільовані пакети моделей. Встановіть його тут, якщо ви плануєте компілювати або квантувати моделі, і виконайте `sima-cli login`, якщо буде запропоновано.

## Наступний крок

Продовжуйте роботу з [DevKit Sync](/getting-started/dev-environment/devkit-sync/), щоб налаштувати спільний доступ до робочого простору, оновлення для парних сесій, резервне копіювання за допомогою rsync та отримати детальну інформацію про команду `dk`.
