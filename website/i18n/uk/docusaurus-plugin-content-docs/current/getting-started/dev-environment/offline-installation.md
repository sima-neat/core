:::tip Коли потрібне автономне встановлення
Використовуйте автономне встановлення, якщо цільовий хост не може завантажити пакети зі служб SiMa.ai.
Це може бути потрібно, якщо ваша організація:

- Блокує завантаження великих файлів.
- Обмежує доступ до реєстрів пакетів.
- Вимагає схвалення перед використанням завантажених пакетів.
- Відокремлює хости розробки від комп’ютерів із доступом до інтернету.
:::

Завантажте пакет на комп’ютері з доступом до інтернету.
Потім перенесіть пакет на цільовий хост для встановлення.

## Виберіть пакет

| Пакет | Призначення | Доступність |
| --- | --- | --- |
| Neat SDK | Налаштування середовища розробки SDK. | SDK 2.1.3.0 або новішої версії |
| Model Compiler | Встановлення Model Compiler у SDK або на окремому хості. | Model Compiler 2.1.3 або новішої версії |
| Neat PCIe | Встановлення Neat на підготовленому хості PCIe та всіх підключених сумісних картах. | 0.6.0 або новішої версії |
| Neat Library (core) | Встановлення пакета core без доступу до інтернету. | 0.6.0 або новішої версії |

## Перед початком

- Встановіть `sima-cli` на комп’ютері з доступом до інтернету. Див. [Встановлення середовища](/getting-started/dev-environment/install-the-environment/).
- Виберіть версію пакета, сумісну з вашою системою. Див. [Сумісність](/getting-started/compatibility/).
- Визначте операційну систему та архітектуру процесора цільового хоста.
- Підготуйте USB-накопичувач або внутрішній спільний файловий ресурс для перенесення.

Комп’ютер для завантаження та цільовий хост можуть мати різні архітектури процесорів.
Виберіть пакет для **цільового хоста**.
Зберігайте всі файли пакета разом, зокрема сценарії, метадані, контрольні суми та залежності.

## Встановіть Neat SDK {#download-the-sdk-offline-package}

### 1. Завантажте пакет

Виконайте одну відповідну команду на комп’ютері з доступом до інтернету.
У цих прикладах використано SDK 2.1.3.0.

Для цільового хоста `amd64`:

<ShellCommand prompt="host">
sima-cli neat install sdk@v2.1.3.0 -t offline-amd64
</ShellCommand>

Для цільового хоста `arm64`:

<ShellCommand prompt="host">
sima-cli neat install sdk@v2.1.3.0 -t offline-arm64
</ShellCommand>

### 2. Встановіть пакет

1. Скопіюйте всю завантажену теку на цільовий хост.
2. Відкрийте термінал у цій теці.
3. Запустіть програму встановлення:

<ShellCommand prompt="host">
bash ./install_offline_sdk.sh
</ShellCommand>

## Встановіть Model Compiler {#download-the-model-compiler-offline-package}

### 1. Завантажте пакет

Перевірте [вимоги до сумісності Model Compiler](/getting-started/compatibility/#model-compiler).
Виконайте одну відповідну команду на комп’ютері з доступом до інтернету.
У цих прикладах використано Model Compiler 2.1.3.

Для цільового хоста `amd64`:

<ShellCommand prompt="host">
sima-cli neat install model-compiler/amd64@v2.1.3 -t offline
</ShellCommand>

Для цільового хоста `arm64`:

<ShellCommand prompt="host">
sima-cli neat install model-compiler/arm64@v2.1.3 -t offline
</ShellCommand>

### 2. Встановіть пакет

Виберіть одне місце встановлення.

**У Neat SDK:**

1. Скопіюйте всю завантажену теку в робочий простір хоста, зіставлений із `/workspace` у контейнері SDK.
2. Відкрийте оболонку SDK.
3. Перейдіть до теки пакета. Для пакета `amd64` використовуйте:

<ShellCommand prompt="sdk">
cd /workspace/model-compiler-offline-amd64
</ShellCommand>

Для пакета `arm64` використовуйте `/workspace/model-compiler-offline-arm64`.

4. Запустіть програму встановлення:

<ShellCommand prompt="sdk">
bash ./install_modelsdk_wheels.sh
</ShellCommand>

**На окремому хості:**

1. Скопіюйте всю завантажену теку на цільовий хост.
2. Відкрийте термінал у цій теці.
3. Запустіть програму встановлення:

<ShellCommand prompt="host">
bash ./install_modelsdk_wheels.sh
</ShellCommand>

### 3. Активуйте Model Compiler

1. Перезапустіть оболонку SDK або оболонку хоста, яку ви використовували для встановлення.
2. Активуйте Model Compiler:

<ShellCommand prompt="sdk|host">
activate-model-compiler
</ShellCommand>

Щоб вийти із середовища Model Compiler, виконайте:

<ShellCommand prompt="sdk|host">
deactivate-model-compiler
</ShellCommand>

## Встановіть Neat для PCIe

Пакет PCIe встановлює Neat на хості та всіх підключених сумісних картах.
Для цього встановлення цільовій системі не потрібні Docker або доступ до інтернету.
Хост повинен мати робоче мережеве з’єднання PCIe з кожною картою.

### 1. Підготуйте хост і карти

Виконайте ці завдання перед запуском програми встановлення Neat:

- Встановіть сумісний драйвер хоста Platform.
- Встановіть відповідну мікропрограму Platform 3.0 на кожній карті.
- Налаштуйте виявлення на інтерфейсі PCIe кожної карти.
- Призначте кожній карті унікальну адресу PCIe IPv4.
- Налаштуйте доступ SSH і довірені ключі хоста SSH для кожної карти.
- Надайте обліковому запису SSH дозвіл використовувати `sudo` на кожній карті.

Програма встановлення Neat не встановлює драйвер Platform і не змінює мікропрограму Platform.
Використовуйте інструкції з налаштування системи, що постачаються з вашим випуском Platform.

### 2. Завантажте пакет

Виберіть версію 0.6.0 або новішу для цільового хоста.
Пакети підтримують хости Ubuntu 22.04 та 24.04 з процесорами `amd64` або `arm64`.

У цьому прикладі версію 0.6.0 завантажують на комп’ютері з доступом до інтернету.
Для цільового хоста Ubuntu 24.04 `amd64` виконайте:

<ShellCommand prompt="host">
sima-cli neat install 'core/pciehost/ubuntu24/amd64@v0.6.0' -t offline -d ./pcie-offline
</ShellCommand>

Для Ubuntu 22.04 замініть `ubuntu24` на `ubuntu22`.
Для хоста `arm64` замініть `amd64` на `arm64`.
Команда завантажує та розпаковує пакет. Вона не встановлює Neat.

### 3. Перевірте систему

1. Скопіюйте всю теку `pcie-offline` на цільовий хост. Використовуйте шлях без пробілів.
2. Відкрийте розпаковану теку `neat-offline`, яка містить `install.py`.
3. Прочитайте наданий файл `INSTALL.md`, щоб дізнатися про необхідні системні інструменти та налаштування SSH.
4. Виконайте перевірки:

<ShellCommand prompt="host">
sudo python3 -B install.py --preflight-only
</ShellCommand>

Програма встановлення автоматично виявляє всі підключені карти. Не вказуйте IP-адреси карт.
Перевірки створюють тимчасові файли, але не встановлюють пакети.
Виправте всі повідомлені помилки перед встановленням.

### 4. Встановіть пакет і перевірте результати

Виконайте цю команду з тієї самої теки:

<ShellCommand prompt="host">
sudo python3 -B install.py
</ShellCommand>

Програма встановлення перевіряє всі карти перед встановленням пакетів.
Спочатку вона встановлює та перевіряє хост, а потім послідовно кожну карту.
Переконайтеся, що підсумковий звіт підтверджує успішне встановлення та перевірку хоста й кожної карти.
Потім виконайте приймальне тестування застосунку.

Якщо встановлення завершилося помилкою, прочитайте діагностичний журнал за вказаним шляхом.
Якщо під час встановлення з’єднання з картою втрачено, перед повторною спробою переконайтеся, що процес встановлення на карті зупинився.
Після помилки програма встановлення не відновлює попередній стан автоматично.

## Встановіть Neat Library (core)

Автономні пакети Neat Library (core) доступні у версії 0.6.0 або новішій.
Використовуйте цей пакет для Modalix DevKit із Platform 3.0 або новішої версії.

### 1. Завантажте пакет

Виконайте цю команду на комп’ютері з доступом до інтернету:

<ShellCommand prompt="host">
sima-cli neat install core@v0.6.0 -t offline
</ShellCommand>

### 2. Встановіть пакет

1. Скопіюйте всю завантажену теку на цільовий хост.
2. Відкрийте термінал у цій теці.
3. Використовуйте інструкції зі встановлення, що постачаються з пакетом.

## Зберігайте пакети у внутрішній мережі {#hosting-packages-internally}

Ви можете зберігати схвалені пакети на внутрішньому файловому сервері.
Зберігайте кожну завантажену теку повністю й окремо від інших версій пакета.
Перенесіть усю теку на цільовий хост перед запуском програми встановлення.
