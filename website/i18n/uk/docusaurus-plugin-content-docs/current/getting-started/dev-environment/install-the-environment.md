Встановіть останню версію Neat SDK. Neat SDK працює як контейнер на вашому хості.

## Необхідні умови

- Підтвердьте, що ваш хост відповідає вимогам.
  [вимоги до хоста](/getting-started/dev-environment/#host-requirements),
зокрема, необхідний доступ адміністратора через `sudo` для встановлення.
- Встановіть `sima-cli` на вашому хості, використовуючи
  [sima-cli installation guide](/tools/sima-cli/).
- Завершіть будь-які налаштування, специфічні для вашого хоста та платформи:
  - [Ubuntu Host Notes](/reference/elxr-sdk-host-setup/ubuntu)
  - [Windows Host Notes](/reference/elxr-sdk-host-setup/windows)
  - [macOS Host Notes](/reference/elxr-sdk-host-setup/macos)

Щоб пізніше використовувати DevKit Sync, вам також знадобиться:

- DevKit, на якому працює сумісне програмне забезпечення для Neat SDK. Докладнішу інформацію можна знайти в [Посібник зі сумісності](/getting-started/compatibility/).
- Ваш хост і DevKit повинні бути в одній мережі, де дозволено трафік NFS.
- Ваша IP-адреса DevKit.

## Встановити

Встановіть поточну версію Neat SDK %%release.sdk_series%%:

<ShellCommand prompt="host">
sima-cli neat install sdk@%%release.sdk_channel%%
</ShellCommand>

Перше встановлення може зайняти кілька хвилин, оскільки відбувається завантаження контейнерного образу Neat SDK. Після завантаження образу, інсталятор запускає налаштування SDK і запитує, чи бажаєте ви підключитися до Modalix DevKit і чи потрібно встановити відповідний Model Compiler всередині SDK.

Якщо ви вирішите підключитися до DevKit, введіть IP-адресу DevKit, коли буде запропоновано. Процес налаштування конфігурує робочий простір SDK, запускає контейнер SDK і налаштовує DevKit Sync. Якщо ви пропустите етап підключення, робочий простір SDK все одно буде створено, і ви зможете підключитися пізніше.

Пакет `%%release.sdk_channel%%` містить останню версію Neat SDK у серії %%release.sdk_series%%. Поточна версія — Neat SDK %%release.sdk%%, яка сумісна з програмним забезпеченням DevKit %%release.platform%%.

Під час налаштування `sima-cli` також пропонує встановити відповідний Model Compiler всередині SDK — прийміть пропозицію, якщо ви самі компілюєте або квантуєте моделі; окремої версії для вибору немає. Пропустіть цей крок, якщо ви використовуєте лише попередньо скомпільовані пакети моделей. Щоб встановити його пізніше, вкажіть конкретну версію або використовуйте окремий хост, див. [Встановіть Model Compiler.](/getting-started/dev-environment/install-model-compiler/) та [Посібник зі сумісності](/getting-started/compatibility/).

### Встановлення конкретної версії SDK {#install-a-specific-sdk-version}

Для SDK 2.1.3.0 і новіших версій використовуйте опублікований тег `v<version>`, щоб встановити конкретну версію, зокрема старіший випуск із виправленнями. Наприклад, виконайте на хості:

<ShellCommand prompt="host">
sima-cli neat install sdk@v2.1.3.0
</ShellCommand>

Префікс `v` є обов’язковим. Не використовуйте `release-<full-version>` як тег конкретної версії. Канал `release-<series>` відстежує останній опублікований випуск у цій серії. Якщо обидва способи вибирають той самий пакет SDK, вони виконують однакові етапи встановлення та налаштування SDK.

Знайдіть опубліковані теги у [випусках SDK](https://github.com/sima-neat/sdk/releases) і виберіть версію, сумісну з програмним забезпеченням DevKit, за допомогою [Посібника зі сумісності](/getting-started/compatibility/).

:::note Застаріла двохетапна інсталяція
SDK 2.0.0, 2.1.2.0 та 2.1.2.1 потребують окремих команд завантаження образу й налаштування. Лише для цих випусків використовуйте [Двохетапну інсталяцію SDK](/reference/two-step-sdk-installation/).
:::

Щоб змінити налаштування SDK після встановлення, див. розділ
[Налаштуйте SDK.](/getting-started/dev-environment/configure-sdk/). Для мережевих середовищ з обмеженим доступом див. розділ
[Встановлення в автономному режимі](/getting-started/dev-environment/offline-installation/).

## Отримайте доступ до SDK.

Після успішного завершення налаштування ви зможете отримати доступ до SDK через термінал, браузер Chrome або VS Code.

### Використовуйте SDK Shell.

Відкрийте командний рядок Neat SDK за допомогою:

<ShellCommand prompt="host">
sima-cli sdk neat
</ShellCommand>

### Використовуйте браузер Chrome.

Neat Insight доступний у межах SDK і його можна відкрити в браузері.
У межах оболонки SDK виконайте команду:

<ShellCommand prompt="sdk">
neat
</ShellCommand>

Вивід `neat` містить розділ **Web Access** із локальними та віддаленими URL-адресами для Insight і браузерного VS Code. Якщо браузер працює на хості SDK, відкрийте локальну URL-адресу `127.0.0.1`. З іншого комп’ютера використовуйте віддалену URL-адресу на основі `NFS_SERVER_HOST_IP`. URL-адреса VS Code відкриває налаштований робочий простір; використовуйте облікові дані, які `neat` показує для встановленого сервера. Див. [Вебдоступ SDK](/reference/environment-variables/) та [Insight](/tools/insight/).

### Використовуйте VS Code.

Виконайте `neat` в оболонці SDK та відкрийте URL-адресу **VS Code (local)** у браузері на хості SDK. З іншого комп’ютера використовуйте **VS Code (remote)**. Для образів із code-server команда `neat` також показує **VS Code password**:

```text
VS Code (local)    https://127.0.0.1:10000/?folder=/workspace
VS Code password   <password shown by neat>
```

Введіть показаний пароль на екрані входу code-server. Пароль не міститься в URL-адресі.

Застарілі образи OpenVSCode натомість використовують URL-адресу з токеном; відкрийте адресу, яку показує `neat`. SDK містить попередньо встановлені розширення Codex і Claude Code для браузерного Code UI.

Нативна версія VS Code – це інший варіант, якщо ви віддаєте їй перевагу замість браузера. Підключіть VS Code до контейнера SDK за допомогою [Контейнери для розробки](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers).

Запустіть `sima-cli login` один раз у контейнері SDK, щоб SDK міг отримати доступ до ресурсів, таких як попередньо створені моделі.

## Оновлення

Щоб повторно встановити або оновити до поточної версії пакета SDK, повторно запустіть команду встановлення, наведену вище, на хості:

<ShellCommand prompt="host">
sima-cli neat install sdk@%%release.sdk_channel%%
</ShellCommand>

Щоб оновити Neat Library у межах наявного контейнера Neat SDK, запустіть Neat
через командний рядок у середовищі контейнера:

<ShellCommand prompt="sdk">
neat update
</ShellCommand>

Це оновлює встановлені компоненти Neat Library у поточній версії Neat SDK. Це не замінює повне оновлення образу контейнера, коли вам потрібні зміни на рівні контейнера.

Якщо ви пізніше видалите або відтворите контейнер Neat SDK, знову запустіть `neat update` всередині нового контейнера.

## Видалити

Щоб видалити встановлений контейнер SDK, виконайте команду:

<ShellCommand prompt="host">
sima-cli sdk remove
</ShellCommand>
