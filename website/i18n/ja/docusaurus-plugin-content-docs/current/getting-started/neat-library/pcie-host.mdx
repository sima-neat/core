このページを使用して、Linuxマシンに接続されたNeat PCIeホストパッケージをインストールします。このLinuxマシンは、Modalix PCIeカードに接続されている必要があります。

Neat PCIeホストパッケージは、ホストマシンから接続されたModalix PCIeカードにデータを送信し、推論結果を受信するコプロセッシングAPIを提供します。

:::warning PCIeホストマシンにインストールします。
このインストールを、Modalix PCIeカードに接続された**PCIeホストマシン**で実行してください。Neat SDKコンテナ内、DevKit上、またはModalix PCIeカード上で実行しないでください。
:::

:::tip オフラインでのインストールが必要な場合
対象が SiMa.ai サービスからパッケージをダウンロードできない場合は、[オフラインでのインストール](#offline-installation)を使用してください。
インターネットに接続されたコンピューターでパッケージをダウンロードしてください。
:::

## 対応するホストのオペレーティングシステム

Neat PCIe ホストパッケージは、以下の検証済みのホストプラットフォームをサポートします。

| オペレーティングシステム | アーキテクチャ | サポート |
| --- | --- | --- |
| Ubuntu 22.04 | x86_64 | 対応済み |
| Ubuntu 24.04 | x86_64 | 対応済み |

Arm64ホストでのビルドは、まだ検証されていません。Windows 11はサポート対象外です。

## オンラインインストールの前提条件

パッケージをインストールする前に：

- PCIeホストに`sima-cli`をインストールしてください。
  [sima-cli installation guide](/tools/sima-cli/).
- 以下の手順に従って、PCIeホストドライバーをインストールし、検証してください。
  [PCIe Driver Installation guide](https://developer.sima.ai/hardware/getting-started/pcie-mode/driver-installation).
- Modalix PCIeカードを接続し、設定して、その管理インターフェースが利用できるようにします。
  ホストからアクセス可能な状態。カード0のデフォルトアドレスは`10.0.0.2`です。
- カードに互換性のある Neat Library のバージョンをインストールします。ホストと
  カードパッケージは、互換性のあるバージョンから提供される必要があります。

PCIeホストを認証し、SiMa.aiのアーティファクトをダウンロードできるようにします。

<ShellCommand prompt="pcie-host">
sima-cli login
</ShellCommand>

## PCIeホストパッケージをインストールしてください。

PCIeホスト上で作業ディレクトリを選択し、インストールされたUbuntuのバージョンに対応するコマンドを実行します。

**x86_64環境におけるUbuntu 22.04:**

<ShellCommand prompt="pcie-host">
sima-cli neat install core/pciehost/ubuntu22/amd64@v%%release.core%%
</ShellCommand>

**x86_64 アーキテクチャにおける Ubuntu 24.04:**

<ShellCommand prompt="pcie-host">
sima-cli neat install core/pciehost/ubuntu24/amd64@v%%release.core%%
</ShellCommand>

インストーラーは、C++ APIや、`~/pyneatpcie` にあるPython環境など、Neat PCIeホストアプリケーションを開発および実行するために必要なものをすべて追加します。

パッケージに同梱された Codex および Claude 向けのコーディングエージェントスキル `neat-pcie-application-builder` もインストールします。PCIe ホストパッケージを再インストールすると、スキルも対応するパッケージバージョンに更新されます。

最初のインストール時、SSH プロビジョニングでは、カードの `sima` アカウントのパスワードを要求できます。これにより、`~/.ssh/sima_neat_pcie_ed25519` が作成または再利用され、その公開鍵がカードにインストールされます。その後、通常の PCIe 動作では、パスワードなしの SSH を使用して、カード側のモデル設定を行います。

## オンラインインストールを確認する

Python API と PCIe ホストプラグインが利用可能であることを確認してください。

<ShellCommand prompt="pcie-host">
source ~/pyneatpcie/bin/activate
python3 -c "import pyneatpcie; print('pyneatpcie ready')"
gst-inspect-1.0 neatpciehost
</ShellCommand>

## トラブルシューティング

SSHによるプロビジョニングでカードを自動的に検出できない場合は、まず、ホストが管理アドレスにアクセスできることを確認してください。

<ShellCommand prompt="pcie-host">
ping -c 1 10.0.0.2
</ShellCommand>

次に、インストールしたセットアップユーティリティを、アドレスを明示的に指定して実行します。

<ShellCommand prompt="pcie-host">
pcie-setup.sh --hosts "10.0.0.2"
</ShellCommand>

パッケージのインストールまたはランタイムの起動に失敗した場合は、PCIeホストパッケージとカードにインストールされているNeat Libraryが、互換性のあるバージョンから提供されていることを確認してください。

## オフラインでのインストール {#offline-installation}

:::caution インストール前に Python の依存関係を確認する
オフラインインストールでは、既存の Python 環境と追加のパッケージやファイルを保持します。パッケージのインストール前に `pip check` を実行し、環境がすでに壊れている場合は停止して、環境のパスと依存関係のエラーを表示します。報告された依存関係を修復してから再試行してください。オフラインで修復する場合は、追加の wheel ファイルが必要です。インストール後にも依存関係を確認し、残っている競合や新たに生じた競合を報告します。パッケージの変更は自動的には元に戻されません。

環境を破棄して新規にインストールする場合に限り、明示的に `./install.sh --recreate-venv`（単体 Core）または `sudo python3 -B install.py --recreate-venv`（PCIe）を実行してください。選択された環境内のパッケージとファイルは、バックアップなしで削除されます。SDK では、このオプションはペアリングした DevKit に適用され、SDK ホストの Python には適用されません。必要なファイルを事前に保存してください。事前確認と検証のみのコマンドでは、環境を再作成しません。
:::

Neat PCIe オフラインパッケージは、バージョン 0.6.0 以降で利用できます。

PCIe パッケージは、ホストと接続されている互換カードすべてに Neat をインストールします。
このインストールでは、対象システムに Docker やインターネット接続は必要ありません。
ホストから各カードへの PCIe ネットワーク接続が動作している必要があります。

### 1. ホストとカードを準備する

Neat インストーラーを実行する前に、次の作業を完了してください：

- 互換性のある Platform ホストドライバーをインストールしてください。
- 各カードに対応する Platform 3.0 ファームウェアをインストールしてください。
- 各カードの PCIe インターフェースで検出を設定してください。
- 各カードに一意の PCIe IPv4 アドレスを割り当ててください。
- 各カードの SSH アクセスと信頼できる SSH ホストキーを設定してください。
- SSH アカウントに、各カードで `sudo` を使用する権限を付与してください。

Neat インストーラーは、Platform ドライバーのインストールや Platform ファームウェアの変更を行いません。
Platform リリースに付属するシステムセットアップ手順を使用してください。

### 2. パッケージをダウンロードする

インターネットに接続されたコンピューターに `sima-cli` をインストールしてください。[sima-cli インストールガイド](/tools/sima-cli/)を参照してください。

対象ホスト用のバージョン 0.6.0 以降を選択してください。
パッケージは、`amd64` または `arm64` プロセッサーを搭載した Ubuntu 22.04 および 24.04 ホストに対応しています。

この例では、インターネットに接続されたコンピューターでバージョン %%release.core%% をダウンロードします。
Ubuntu 24.04 の `amd64` 対象ホストの場合は、次を実行してください：

<ShellCommand prompt="host">
sima-cli neat install 'core/pciehost/ubuntu24/amd64@v%%release.core%%' -t offline -d ./pcie-offline
</ShellCommand>

Ubuntu 22.04 の場合は、`ubuntu24` を `ubuntu22` に置き換えてください。
`arm64` ホストの場合は、`amd64` を `arm64` に置き換えてください。
このコマンドはパッケージをダウンロードして展開します。Neat はインストールしません。

### 3. システムを確認する

1. `pcie-offline` ディレクトリ全体を対象ホストにコピーしてください。スペースを含まないパスを使用してください。
2. `install.py` を含む、展開済みの `neat-offline` ディレクトリを開いてください。
3. 必要なシステムツールと SSH 設定について、付属の `INSTALL.md` を読んでください。
4. チェックを実行してください：

<ShellCommand prompt="host">
sudo python3 -B install.py --preflight-only
</ShellCommand>

インストーラーは接続されているすべてのカードを自動的に検出します。カードの IP アドレスは指定しないでください。
チェックでは一時ファイルを作成しますが、パッケージはインストールしません。
インストール前に、報告されたエラーを修正してください。

### 4. インストールして結果を確認する

同じディレクトリから次のコマンドを実行してください：

<ShellCommand prompt="host">
sudo python3 -B install.py
</ShellCommand>

インストーラーは、パッケージをインストールする前にすべてのカードを確認します。
最初にホストをインストールして検証し、次に各カードを順番に処理します。
最終サマリーで、ホストとすべてのカードのインストールおよび検証が成功したことを確認してください。
次に、アプリケーションの受け入れテストを実行してください。

インストールに失敗した場合は、表示されたパスの診断ログを読んでください。
インストール中にカードへの接続が失敗した場合は、再試行前にカードのインストールプロセスが停止したことを確認してください。
失敗しても、インストーラーは以前のインストール状態を自動的には復元しません。

## 次のステップ

[PCIeによる共同処理](/develop-apps/hello-neat/pcie/) を使用して、ホストからカードへの完全な開発パスを検証してください。

オフラインインストールでは、ホストの既存の `~/pyneatpcie`、またはカードや DevKit の既存の `~/pyneat` を再利用します。シンボリックリンクの場合はリンク先を再利用します。ホームに環境がない場合、カードや DevKit は、インストールするユーザーが NVMe に書き込めるときは `/media/nvme/pyneat`、それ以外は `~/pyneat` を使用します。新しい NVMe インストールでは、既存のホーム環境を置き換えずに `~/pyneat` リンクを作成します。
