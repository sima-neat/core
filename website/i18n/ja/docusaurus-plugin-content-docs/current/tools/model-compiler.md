# Model Compiler

Model Compiler は、学習済みのモデルを Neat が読み込んで実行できる、Modalix 形式のモデルアーカイブに変換します。

以下の状況でご使用ください。

- モデルがSiMa.aiプラットフォームに対応しているか確認します。
- 対応するモデルを量子化およびコンパイルします。
- Neatアプリでアーカイブを使用する前に、精度とパフォーマンスを検証します。

タスクのワークフローについては、[モデルをコンパイルする](/compile-a-model/) から始めてください。API のリファレンス資料については、[Model Compiler API](/reference/model-sdk-api/) を参照してください。
