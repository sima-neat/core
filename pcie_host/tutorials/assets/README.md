# Tutorial image assets

- `street-scene.png` is the 640x480 detection-oriented scene used by the
  YOLOv8s tutorials. It contains multiple people and vehicles.
- `labrador.jpg` is used only for ResNet-50 classification. It is the same image
  distributed in the documentation as
  `docs/images/hello-neat-pcie-labrador.jpg`. Both copies are derived from
  [YellowLabradorLooking new.jpg](https://commons.wikimedia.org/wiki/File:YellowLabradorLooking_new.jpg),
  photographed by Elf and modified by Djmirko and FT2, under
  [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).
