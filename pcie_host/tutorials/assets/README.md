# Tutorial image assets

- `street-scene.png` is the 640x480 detection-oriented scene used by the
  YOLOv8s tutorials. It contains multiple people and vehicles.
- `labrador.jpg` is used only for ResNet-50 classification. It is derived from
  Wikimedia Commons file `YellowLabradorLooking_new.jpg`, photographed by Elf
  and modified by Djmirko/FT2, under CC BY-SA 3.0.
