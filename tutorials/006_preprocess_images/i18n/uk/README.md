## Concept

Налаштуйте етап попередньої обробки — формат, розміри та нормалізацію для кожного каналу, — щоб необроблене вхідне зображення перетворювалося саме на такий тензор, на якому навчали вашу модель. Точна попередня обробка зазвичай і відрізняє модель, яка працює, від моделі, яка здається несправною.

## Walkthrough

Скомпільована модель очікує вхідні дані однієї точної форми й діапазону значень: фіксований порядок кольорів, фіксовані розміри та рецепт нормалізації, з яким її навчали. Попередня обробка — це етап, що бере необроблене декодоване зображення й перетворює його саме на такий тензор. Якщо помилитися, модель однаково працюватиме — просто впевнено видаватиме нісенітниці; тому попередню обробку перевіряють першою, коли розгорнута модель «здається несправною».

У цьому розділі налаштовуються параметри попередньої обробки, які потрібні найчастіше, — формат кольору, розміри входу й виходу, поведінка зміни розміру та нормалізація `mean`/`stddev` для кожного каналу, — а потім ми переглядаємо граф попередньої обробки моделі й лише після цього пропускаємо один детермінований тензор через усю модель. Наприкінці ви оголосите повний контракт попередньої обробки, приєднаєте його до моделі й переконаєтеся, що налаштований маршрут існує.

### Налаштування контракту попередньої обробки {#step-configure-preproc}

Ці параметри оголошують контракт, який забезпечує етап попередньої обробки. `format` (або `color_convert.input_format`) фіксує порядок кольорів на вході; поля `input_max_*` обмежують динамічні вхідні дані, які прийматиме середовище виконання; цільові розміри масштабування й виходу задають розмір тензора, що подається на інференс; а `normalize` разом зі сталими `mean`/`stddev` для кожного каналу виконують масштабування значень. Сталі нормалізації мають відповідати рецепту, з яким модель навчали, — невідповідна статистика найчастіше спричиняє вихід із низькою впевненістю.

**C++:** Поля містяться в `Model::Options::preprocess`: `color_convert.input_format` приймає значення переліку `PreprocessColorFormat`, `normalize.enable` має тип `AutoFlag`, а `normalize.mean` / `normalize.stddev` — `std::array<float, 3>`.

**Python:** Поля містяться в `ModelOptions.preprocess`: `color_convert.input_format` приймає значення переліку `PreprocessColorFormat`, `normalize.enable` має тип `AutoFlag`, а сталі — це списки, які присвоюють `normalize.mean` / `normalize.stddev`.

### Створення моделі {#step-load-model}

Створення `Model` зі шляху до архіву та параметрів прив’язує ваш контракт попередньої обробки до завантаженої моделі. Відтепер модель несе визначення попередньої обробки із собою, тож будь-який етап чи запуск, отриманий із неї, використовує той самий рецепт.

### Окрема перевірка попередньої обробки {#step-inspect-preproc}

У цьому розділі фрагмент попередньої обробки перевіряється до запуску повної моделі, щоб ви могли переконатися, що маршрут існує, перш ніж налагоджувати щось далі за конвеєром.

**C++:** `stages::Preproc(frames, model)` виконує лише крок попередньої обробки й безпосередньо повертає попередньо оброблений `Tensor` — ми читаємо `pre.shape.size()` (ранг) і `pre.dtype`, щоб підтвердити, що контракт набув чинності.

**Python:** `model.preprocess()` повертає фрагмент `Graph` попередньої обробки, тож ми виводимо `describe()`, щоб переглянути налаштований маршрут; наступний виклик `model.run([tensor])` проходить увесь шлях і повідомляє кількість виходів.

## Run

Команди **Python** і **C++ (prebuilt)** запускайте з **кореневої теки встановлення Neat** (теки, що містить `share/` і `lib/`), а команди **build from source** — з **кореневої теки репозиторію**.

**Python:**
```bash
python3 share/sima-neat/tutorials/006_preprocess_images/preprocess_images.py \
  --model /tmp/resnet_50.tar.gz --size 224
```

**C++ (prebuilt):**
```bash
./lib/sima-neat/tutorials/tutorial_006_preprocess_images \
  --model /tmp/resnet_50.tar.gz --size 224
```

**C++ (build from source):**
```bash
./build.sh --target tutorial_006_preprocess_images
./build/tutorials-standalone/tutorial_006_preprocess_images \
  --model /tmp/resnet_50.tar.gz --size 224
```

Очікуваний результат (версія для C++ виводить ранг попередньо обробленого тензора та значення переліку dtype):

```text
preproc_rank=3
preproc_dtype=1
[OK] 006_preprocess_images
```

(Версія для Python виводить `preproc_graph=ready`, опис графа та `output_count=...`.) Щоб інтегрувати початковий код C++ цього розділу у свій проєкт із власним файлом `CMakeLists.txt` (тека extras не потрібна), див. розділ [Як запускати навчальні посібники](/tutorials#compile-a-copy-yourself) на головній сторінці.
