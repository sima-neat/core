## Concept

Додайте скомпільовану модель до публічного `Graph` за допомогою `graph.add(model)` — так ви отримаєте оркестрацію на рівні графа (маршрутизацію, планування, додаткові входи й виходи) навколо виконання моделі, не втручаючись у внутрішній граф середовища виконання.

## Walkthrough

У розділі 003 ми побудували граф лише з вузлів входу й виходу; у розділі 001 запускали модель як окремий об’єкт. Цей розділ поєднує обидва підходи: `Model` сама є вузлом, сумісним із графом, тож її можна вбудувати в публічний `Graph` так само, як будь-який інший етап. Це шаблон-міст, до якого вдаються виробничі системи, коли їм потрібен контроль на рівні графа — кілька входів, іменовані виходи, власна маршрутизація, — а виконання моделі має й далі лишатися одним фрагментом для повторного використання.

Ключова ідея в тому, що ви ніколи не торкаєтеся низькорівневого графа середовища виконання, `StageModelExecutorOptions` чи внутрішніх ідентифікаторів вузлів. Ви передаєте модель у `graph.add(...)`, а Neat під час побудови перетворює цей фрагмент (попередню обробку / інференс / постобробку — за потреби) на правильний внутрішній план виконання. Наприкінці ви вбудуєте модель у публічний граф, виведете складену топологію й прочитаєте кількість виходів моделі.

### Завантаження моделі {#step-load-model}

Конструктор завантажує скомпільований архів і готує його до виконання — так само, як у розділі 001. Тут ми передаємо лише шлях, без об’єкта параметрів, бо цей розділ присвячено композиції, а не попередній обробці. Отримана `Model` — це тепер об’єкт, який розуміє шар графа.

### Складання моделі в граф {#step-compose-graph}

У цьому й полягає вся суть розділу. До нового `Graph` по черзі додаються три вузли: іменована межа входу, сама модель та іменована межа виходу. Оскільки `Model` сумісна з графом, `add(model)` додає весь маршрут моделі як один фрагмент — без жодного спеціального API й без втручання в середовище виконання. Виведення `graph.describe()` показує складену топологію, щоб ви могли переконатися, що модель опинилася між іменованими межами.

**C++:** Межі беруться з `simaai::neat::nodes::Input("image")` і `nodes::Output("result")`; модель передається безпосередньо в `graph.add(model)`.

**Python:** Межі беруться з `pyneat.nodes.input("image")` і `pyneat.nodes.output("result")`; модель передається безпосередньо в `graph.add(model)`.

### Аналіз моделі {#step-inspect-model}

Нарешті ми читаємо, що саме додає фрагмент моделі. Це підтверджує, що модель завантажилася правильно, і показує топологію виходів, яку граф видаватиме далі за потоком.

**C++:** `model.info()` повертає структуру з інформацією; ми виводимо `model_name`, а також `output_topology.physical_outputs` і `logical_outputs`, щоб з’єднання виходів моделі було явним.

**Python:** Прив’язка для цього розділу просто виводить рядок, який підтверджує, що фрагмент моделі додано до публічного графа.

## Run

Для цього розділу потрібен архів моделі (`yolo_v8s`). Команди **Python** і **C++ (prebuilt)** запускайте з **кореневої теки встановлення Neat** (теки, що містить `share/` і `lib/`), а команди **build from source** — з **кореневої теки репозиторію**.

**Python:**
```bash
python3 share/sima-neat/tutorials/014_embed_model_inside_graph/embed_model_inside_graph.py \
  --model /tmp/yolo_v8s.tar.gz
```

**C++ (prebuilt):**
```bash
./lib/sima-neat/tutorials/tutorial_014_embed_model_inside_graph \
  --model /tmp/yolo_v8s.tar.gz
```

**C++ (build from source):**
```bash
./build.sh --target tutorial_014_embed_model_inside_graph
./build/tutorials-standalone/tutorial_014_embed_model_inside_graph \
  --model /tmp/yolo_v8s.tar.gz
```

Очікуваний результат (версія для C++ спочатку також виводить опис складеного графа):

```text
model=yolo_v8s physical_outputs=1 logical_outputs=1
[OK] 014_embed_model_inside_graph
```

(Версія для Python виводить опис графа, а потім `model fragment added to public Graph`.)

Щоб інтегрувати початковий код C++ цього розділу у свій проєкт із власним файлом `CMakeLists.txt` (тека extras не потрібна), див. розділ [Як запускати навчальні посібники](/tutorials#compile-a-copy-yourself) на головній сторінці.
